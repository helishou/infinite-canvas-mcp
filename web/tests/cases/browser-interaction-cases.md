# 无限画布 · 浏览器交互用例库（画布 + 剧目）

> 这是一份**上浏览器照着点**的交互用例库。每条都写清入口路径、具体点击对象、可观察的预期结果，执行时在「实测」列填写通过/失败。
> 取代 `canvas-frontend.md`（抽象基线版）。范围：画布域 + 剧目域。
>
> **页面基线（2026-11-19 确认）**：新页面 = 画布 `/canvas/:id` + 新制作台 `/drama-studio`（影策对照文档中的「本地新制作台」）。老页面 = 规划页 `/production?...workspace=series`、单集制作台 `/director/:id`——均已标注「老页面-可能下线」，不作为主要回归对象。H3 时间线 / Clip 编译生成类能力尚在新制作台缺席，相关用例已暂删，待新制作台补齐后再加回。
>
> **现场核对依据**（2026-11-19 实浏览器读取，URL `http://localhost:3001`）：
> - 首页 `/`：创作台（图片/视频/文本/音频/导演）、画幅、张数、参考内容、「生成图片」、「新建空白画布」、「剧目制作」「自由画布」「最近画布」「最近生成」、右下「导演」面板。
> - 项目列表 `/projects`：「新建剧目」「新建画布」「导入画布」「本机草稿」、项目卡片含「画布视图 / 制作视图」与节点数·连线数·更新时间。
[新制作台] > - 剧目工作室 `/drama-studio`：顶栏「新建短剧」+ 剧目名切换；一级 tab「制作 / 项目资产 / 待处理 / 设置」；工具栏「（一键全自动 / 已全部完成，随制作状态变化）/ 资产包 / 工具 / 精修画布 / 暂停」；状态过滤「全部 N / 需要处理 N / 制作中 N / 已完成 N」；「按原文批量建集」「添加第 N 集」；内容 tab「剧本 / 分镜 / 成片」；动作「分镜改编 / 拆镜 / 导演讨论 / 在画布中打开本集」；梗概区「改编过程 / 重新改编 / 展开全部（显示前 3 句）/ 编辑原文」；队列区「全部重试 / 展开队列」。
> - 画布页 `/canvas/:id`：项目标题（如「自由画布」）、顶部连接横幅、右侧导演面板。
>
> **文案来源**：全部按钮文案已通过实浏览器 DOM 抓取 + i18n / 组件源码交叉核对（见文末「文案核对记录」）；任务执行中若产品改版，以实际 UI 为准并更新记录。

## 执行规则

- **入口写法**：`URL → 按钮文案` 表示先到该地址再点该按钮；`按钮A → 按钮B` 表示同页连续点击。
- **实测结果**：`通过` / `失败` / `跳过-环境` / `阻塞`。失败请写实际现象与用例 ID，不要改预期来迁就结果。
- **环境**：Web `http://localhost:3001`，Backend `http://127.0.0.1:17370`（`/health` 应返回 `{"ok":true,...}`）。
- **生成类用例**需已配置模型渠道或 ComfyUI；不满足标 `跳过-环境`，不要标失败。
- **数据保护**：执行前确认重要画布/剧目已备份；涉及删除的用例优先用临时项目/临时剧目。
