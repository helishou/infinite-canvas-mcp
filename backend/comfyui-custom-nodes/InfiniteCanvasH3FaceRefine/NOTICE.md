This package includes code adapted from AIMixer's `ComfyUI_MiniMaxH3_Director`
(Apache License 2.0) and face tracking, stitching, and H3 latent-injection
implementations adapted from Carasibana's `ComfyUI-H3-FaceRefine` (MIT License).
The applicable license texts are included in `third_party/`. The local runtime
uses ComfyUI's native MiniMax H3 conditioning and sampling nodes; it does not
import or require the Director plugin at runtime.
