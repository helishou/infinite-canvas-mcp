# H3 潜空间二采确认

将此目录安装到所用 ComfyUI 的 `custom_nodes` 后重载 ComfyUI。依赖现有南风 V15、H3 潜空间放大兼容节点及模型，无新增 Python 包。

画布「H3 潜空间放大二采 → 一采确认模式」开启后，Backend 原任务先生成并展示一采，暂停等待用户确认。确认后加载同一任务保存的联合视频/音频潜变量、参考条件和剩余 Sigma，执行原生潜空间放大及二采；不从 MP4 重编码，不重新执行一采。关闭开关时继续原生连续两采。

一采/二采步数与完整 Sigma 在启动时固定；暂停时可调整放大模型、目标尺寸、精度和后处理参数。二采失败可显式重试，也可保留一采或放弃；重复确认不会重复生成。

快照保存在 ComfyUI `output/infinite-canvas-h3-confirmation`，按 Backend 父任务、节点和 Clip 派生的身份隔离。它们是未完成任务的恢复数据，请保留；Backend 或 ComfyUI 重启后仍可读取。缺失或结构不兼容时明确拒绝继续，不自动重跑。张量保存到 CPU 并使用 `weights_only=True` 加载，保留 H3 NestedTensor 的视频与音频分量。

节点只在运行时改写原生 V15 展开图的采样边界，保留已有模型补丁、释放依赖、锁音频、首尾帧条件同步、RTX/DLSS 和输出链。原生图结构变化而无法识别边界时拒绝执行。
