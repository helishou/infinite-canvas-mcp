# 角色设计 · 特写+三视图+局部细节（中文）

> **版权声明**：作者 AI搅拌手（导演大师）。本 Skill 为专有内容，未经授权禁止复制、二次分发、转售或用于其他产品。


写一张可直接打文生图的角色设定板提示词。在特写和三视图之下增加底部局部细节条，不要文字说明区。**正文必须是简体中文。**

## 输入

用户会提供 `name`、`description`、`styleLock`、`styleNotes`，以及 `profile`（性别、年龄、身份、外貌、性格、身份锁）。**优先吸收 `profile` 与 `identityLock`**。把看得见的辨识点写进特写和局部格。动机、冲突只转成气质。

## 输出契约

- `prompt` 第一行必须是：**特写+三视图+局部细节**
- 其后按「画面分段」逐段书写，每段单独起行，段首用固定标记。
- 最后一段必须是【画风】。根据 `styleNotes` 生成笔触、色调、光质、边缘和质感，不要原样复读。`styleNotes` 为空时对齐 `styleLock`。
- 整图一张设定板，横向 16:9，白底或干净深底。同一人、同一套服装、同一发型。
- **正文用简体中文连贯描述。** 不要英文句子或英文关键词串。人名、品牌可保留原文。

## 画面分段

### 【面部特写】

- 位置：主区左侧，高清头肩或大头。
- 必须写清：五官、眼神、发型与发际线、妆容、皮肤质感，以及脸上的标志疤痕、痣、瞳色。
- 本段不要：全身像、底部小格、右侧文字。

### 【三视图】

- 位置：主区中部，三张全身站姿并排。
- 必须写清：正面、侧面、背面；脚底对齐；体型、服装形制、鞋。三张服装与体型锁定为同一套。
- 本段不要：大头特写、文字面板。

### 【局部细节】

- 位置：画面底部一排，5 到 8 个小格。
- 每一格只写一个看得见的辨识点，并逐格写清画什么。从外貌和 `identityLock` 里挑，例如：眉尾疤、瞳色、皮肤纹理、领口或纽扣、手表或戒指、指节、发型后视、标志配饰。
- 每一格都与主图是同一人。
- 本段不要：身份介绍、身高数字列表、性格词、色卡。

## 整图禁止

右侧或任何位置的人设文字面板、身份关键词、身高体型条目、服装主色列表、性格关键词、主色色卡、分镜、多角色。
