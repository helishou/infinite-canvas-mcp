# 短剧06 · 分镜图提示词

> **版权声明**：作者 AI搅拌手（导演大师）。本 Skill 为专有内容，未经授权禁止复制、二次分发、转售或用于其他产品。


只写**当前镜头的一张静帧**。输出给图像模型用的中文 `framePrompt`。不要写视频提示词，不要写 H3 结构，不要写秒数，不要写运镜过程。

`focusShotId` 有值时只写那一镜。

## 用哪些信息

按这个优先级取画面，不要发明画面里没有的人、物和地点：

1. `beats` 是这一镜的时间轴。静帧只取最能代表该镜的一段，不要把整条时间轴画进去。没有 `beats` 时用 `visual`。
2. `size` / `sizeLabel` 是景别。提示词开头用中文景别词。已是中文就原样用；英文缩写按常见景别译成中文（大远景、全景、中景、中近景、近景、特写）。
3. `referenceDefs` 或 `extra` 里的「图N 是…」是这一镜参考图的定义。提示词里的人物、场景、道具必须和这些定义一致，直呼角色名。不要把图1写成图2。没有定义的编号不要虚构身份。同一条如果带有「补充说明」，这句是用户对这个参考素材的说明，要写进对应描述，不要因此改编号和身份。没有补充说明就不要编造。
4. `dialogue` 只在表情或口型能看出来时轻轻带一句，不要把整句对白写进画面。
5. `camera` 只转成一个静止瞬间（例如「正回头」「手伸向柚子」），不要写「镜头推进」「摇镜」。
6. 项目 `styleLock` 不要整段抄进提示词，画面本身说清楚即可。

若 `linkPrev` 为 true，这一镜是上一镜同一长镜头的下一段。静帧要接上 `prevShot` 结尾时的主体位置和动作方向，仍然只画这一瞬间。

## 写法

中文，两到四句，适合直接出图：

- 开头是景别
- 接着是谁、在哪、正在做什么（一个瞬间）
- 然后是站位、光线、关键道具

不要出现字段名、镜头编号、秒数、`Picture`、`Shot`。

## 输出 JSON

只输出这一段 JSON，不要 markdown。

```json
{
  "framePrompt": "中近景，阿梨抱着厚厚的本子站在小凳旁，笔尖在纸上抖出一小团墨点，正给柚子去瓣，耳朵紧紧地竖着。"
}
```
