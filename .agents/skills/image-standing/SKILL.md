# 站位设计 · 生图提示词

> **版权声明**：作者 AI搅拌手（导演大师）。本 Skill 为专有内容，未经授权禁止复制、二次分发、转售或用于其他产品。


写一张可直接打文生图的站位主图提示词，并同时声明本站位需要带入生图的参考图清单。整张画面只有一个机位、一个瞬间，用来锁人物站位与空间关系。

## 输入

用户会提供 `name`、`description`、`lighting`、`landmarks`、`styleLock`、`styleNotes`、`aspect`，以及 `availableLibrary`（资产库里可作参考图的角色/场景/道具，含是否已有设定图）。

- 人物站位、朝向、距离以 `landmarks` 为准，再吸收 `description` 里的调度意图。
- `referenceImages` 必须从 `availableLibrary` 里选，名字与资产库原名一致；只选本站位真正需要锁外貌/布局/外观的项。
- 有对应设定图（`hasImage=true`）的优先列入；没有设定图的不要硬写进 `referenceImages`。
- `styleNotes` 是画风说明。用它生成【画风】，不要原样复读。
- 画幅跟随 `aspect`，默认 16:9。画面必须铺满这个画幅。

## 参考图约束（必守）

- `referenceImages` 数组顺序即生图参考图顺序：第 1 项 = 参考图1，第 2 项 = 参考图2……
- `prompt` 正文【站位】段开头必须按同一顺序写清：`参考图1是角色「果果」`、`参考图2是场景「邮局门口」主图` 等；名字与 `referenceImages` 完全一致。
- **主体与编号一一对应：** 正文里凡写到「参考图N」，所指主体必须是 `referenceImages[N-1]` 那一项。例如参考图1是张三，则只能写「张三外貌跟参考图1」。
- 没有可用参考图时，`referenceImages` 为 `[]`，正文不要编造「参考图1」。
- 有参考图时，角色外貌、场景布局、道具外观分别锁对应编号，不要另起一套。

## 输出契约

- **只输出一个 JSON**，不要 markdown 代码块，不要前后解释。
- `prompt`：提示词正文。第一行必须是 `站位主图`；其后按画面分段书写；整图只有一张主图；正文用简体中文；【画风】在【负面】之前。
- `negativePrompt`：负面提示词。
- `referenceImages`：本站位需要带入生图的参考图清单，每项 `{ "type": "character"|"scene"|"prop", "name": "资产原名" }`。

## 画面分段（写在 prompt 里）

### 【站位】

- 若有参考图，先按 `referenceImages` 顺序写 `参考图1是…`，再写机位与人物站位。
- 写清机位高度与取景范围、左右前后、朝向与距离。
- 角色名用资产名，并与参考图声明一致。

### 【空间】【光线】【道具】

- 空间落在可复用场景里；有场景参考图则跟参考。
- 光线优先用输入 `lighting`。
- 关键道具写清位置；有道具参考图则锁外观。

## 整图禁止

多格分镜、四向机位、纯文字说明条、UI 标注线、箭头指示牌（除非故事里真有路牌）。不要写成纯空景。

## 输出 JSON 示例

```json
{
  "prompt": "站位主图\n【站位】\n参考图1是角色「果果」。参考图2是角色「老钟」。参考图3是场景「邮局门口」主图。中景平视。果果站在画面左侧靠近木牌，面向右，外貌跟参考图1；老钟站在画面右侧柜台后，面向左，外貌跟参考图2，两人相距约两步。空间布局跟参考图3。\n【空间】\n门口青石地面，木牌在左，柜台在右。\n【光线】\n夜景，主光来自右上灯笼。\n【画风】\n暖夜色。画风名用 styleLock。\n【负面】\n多格分镜，四向机位，文字标注，箭头",
  "negativePrompt": "多格分镜，四向机位，文字标注，箭头",
  "referenceImages": [
    { "type": "character", "name": "果果" },
    { "type": "character", "name": "老钟" },
    { "type": "scene", "name": "邮局门口" }
  ]
}
```
