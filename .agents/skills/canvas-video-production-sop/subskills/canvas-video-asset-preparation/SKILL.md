# 资产准备

## 内嵌提示词规范

常规角色、场景和道具资产直接使用本节，不要完整读取外部大规范。

- **建与改分流**：基于参考建立新资产用 Neo Image 2；按“参考图标注 → 主体 → 特效层（没有则省略）→ PRESERVE/CONSTRAINTS → PHOTOGRAPHIC TONE → Avoid → size/quality”组织重型 prompt。只修改现成图的一处用 Neo Nano Pro 中文短句：`<改动项>。其他全部保持不变。`
- **参考图一图一职**：逐张写“只锁什么、不提供什么”。角色图只锁身份/发型/服装/体型，场景图只锁空间/家具/材质/光线，道具图只锁结构/材质，构图图只锁位置/朝向。多角色时把每张身份图绑定到画面方位，并在 CONSTRAINTS 与 Avoid 排除串脸、合脸和身份互换。
- **角色首轮建档内容顺序**：画质与光线 → 身份、年龄和族群 → 气质与体型 → 哑光皮肤 → 妆发、五官与双眼 → 服装、鞋履与配饰 → 姿态 → 镜头与棚拍背景。写成一段自然中文，不机械照抄现代服装、固定滤镜或导演名。
- **无人场景首轮建档内容顺序**：空间结构 → 具体物件布局与材质磨损 → 光源方向与色温 → 空气环境 → 摄影质感 → 胶片/显影倾向 → 焦段、光圈与景深。默认无人，避免角色外观描述混入场景锚。
- **角色资产两步走**：写实角色先用半身身份图锁脸与服装，确认后再扩四视图；不要在身份未定时直接摊成多格。
- **资产设定图**：结构展示使用 `orthographic, no perspective distortion`；比例敏感的资产加入人物剪影、等高武器或同类物作图内尺度锚；灰底物料明确 `single isolated object, clean neutral background, no environment`。

只有制作本节未覆盖的生物、载具、武器多视图等特殊资产时，才在 [Neo Image 图型库](../../references/neoimage-prompt-engine-公开版.md) 中按标题局部查阅对应图型（如“图型 15”“图型 18”“图型 20”），不得通读全文。若常规角色或场景出现结构缺口，再按小节标题局部查阅 [角色与场景规范](../../references/角色资产与场景生成-即梦5或MJ.md)。

## 资产清单与唯一职责

盘点角色节点、角色身份图、时代服装四视图、无人场景锚、道具锚、综合色彩参考、站位图、关系板、已验收关键帧和已完成视频。每个资产记录：

```text
assetId / nodeId / 类型 / 标题 / 版本
适用人物、时代、场景或镜头
唯一职责
storageKey / 来源任务 / 当前状态
```

每张输入图只承担一个主要职责：场景锁空间/家具/材质/光线，人物锁身份/服装/体型，道具锁规格与物理状态，站位图锁位置/朝向/轴线，上一镜关键帧锁承接状态。只连接当前任务真正需要的参考，避免职责冲突。

## 角色与服装

- 角色节点是身份真值。生成节点的 `referenceNodeIds` 登记原生 `character` 节点 ID；具体服装用 `characterReferences[characterNodeId].imageKeys` 选择。
- 站位图、分镜与多人剧情图默认使用角色节点中对应时代的无字四视图，标记 `referenceType: "character-four-view"`；不得用头像、半身图或历史散图冒充。
- 写入服装选择后回读 `characterImages`，确认 image key、角色、服装名称和时代一致；缺失时先补资产，不用其他角色或普通图片节点顶替。
- 四视图默认无字：左上锁骨以上正脸、右上锁骨以上侧脸、左下从锁骨以下开始且头脸完全被裁掉的无头正面服装全身、右下从后脑到鞋底的完整背面。约束与排除都写 `no text / no letters / no numbers / no symbols / no watermark / no logo / no UI`。出现字符或左下出现头脸即失败，不能靠裁切交付。

## 道具连续性

跨镜头道具必须有稳定 `propId/assetId` 和状态表：

```text
规格锁：材质、比例、颜色、纹样、文字、磨损、厚度、开合/收鞘状态
首次/最后出现镜头
每镜状态：持有者、画面侧、左右手、位置、朝向、可见面、遮挡
状态迁移：上一镜末 → 本镜冻结状态 → 下一镜允许变化
```

纸张按折叠、展开、折痕、受力与厚度连续；硬道具按形制、朝向、挂载侧和开合状态连续。长兵器必须能看到连续的柄、口、身与尾；短刀感、露刃、裁尾、第二把武器或装饰漂移均标记 `rejected_visual`。

## 参考白名单

为每个待生产镜头预留可回读 manifest：

```text
shotId
requiredCharacters / requiredProps / requiredSceneRefs
actualReferences（按顺序记录 nodeId、type、role、storageKey）
unexpectedReferences / missingReferences / staleMetadataReferences
```

画面未出现的人物不得因前后镜连续或站位图完整而被额外传入。若只需要手部，显式写“手部局部/画外身体”。站位图含无关人物时，改用无人场景锚与本帧人物白名单，或先制作干净的站位版本。

## 阶段内验收与完成闸门

资产生成或登记后立即在本 Skill 内验收，不转交独立验收阶段：

- 回读精确节点、版本、storage key、来源任务和实际媒体；旧媒体或任务成功不能冒充本轮资产。
- 角色检查身份、年龄、体型、时代服装、发型和可复用视角；四视图逐格检查正脸、侧脸、无头正面服装全身、完整背面及无文字要求。
- 场景检查空间结构、家具尺度、材质、光源方向、时代物件与无人要求；道具检查结构、比例、材质、纹样和开合/折叠/收鞘状态。
- 发现问题时只返修该资产及其直接依赖；先定位身份、服装、结构、参考职责或 prompt 中的一个主要原因，不重跑已通过资产。
- 使用 `accepted / needs-redo / waiting-user / blocked-input` 记录结果。只有 `accepted` 资产可以成为下游正式参考；自检通过但用户要求确认时标记 `waiting-user`。

- 本轮需要的角色、时代服装、场景和道具都有精确节点与版本。
- 每个参考只有一个清楚职责，缺失和意外参考均为零或已有明确豁免。
- 资产已完成上述视觉与结构验收，未把生成成功误记为通过。
- 当前采用资产及其 nodeId、assetId、storageKey 和状态已登记在制作目录的 `assets.md` 与 `progress.md`。
- 未进入镜头设计或生成阶段。
