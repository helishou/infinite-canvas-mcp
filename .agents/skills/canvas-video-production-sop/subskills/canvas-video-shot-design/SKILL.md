# 镜头设计

## 入口条件

先回读剧情段、连续性台账、资产清单、色卡版本与站位覆盖。缺少会改变构图或动作因果的上游真值时，返回对应阶段，不靠镜头文字猜测。

## 设计原则

- 每个镜头服务一个主要叙事功能，并有清楚的开始状态、可见变化与结束状态。
- 不用静态末帧替代动作设计。蹲下、起身、转身、冲出、追出、关门或形成空镜，都要说明从上一状态如何抵达。
- 文字分镜表中的静态关键帧默认选本镜动作的起始状态，承接上一镜末状态；动作在后续 Clip 中完成。静态反应、空镜或明确要求结果画面时，在镜头表注明改选的状态。
- 情绪按剧情递进，落实为视线、呼吸、手部、身体重心、停顿和动作速度，而不是只写抽象形容词。
- 固定 180° 轴线、人物屏幕方位、目光方向、摄影机物理区域与家具关系。若有越轴，必须写明建立镜头或可理解的过渡。
- 手部特写交代手腕、袖口、前臂与画外身体连接；桌面插入镜头锁定桌面尺寸、高度、道具朝向与角色方向；近景注明仍需保留的腿、家具边缘或前景锚。
- 声音与画面分层：逐字台词、说话人、语速、音量、停顿、呼吸、环境声、动作音与 BGM 单独记录，不把这些内容塞进静态图片 prompt。

## 道具与空间约束（文字道具 / 家具路线 / 屏风）

适用于镜头表涉及信件、契约、账册、署名纸条或家具与门路线重要的镜头。

### State table：写提示词前先建表

解析源 CSV 后，每个相关镜头一行，明确这些字段：

| Field | Required question |
|---|---|
| `holder` | Who physically holds the prop at the start and end of the shot? |
| `contact` | Which hands touch it, and is the contact a grip, handoff, throw, pickup, or release? |
| `form` | Closed cover, folded packet, partly opened, or fully open for reading/writing? |
| `surfaceFacing` | Which actor can read the cover/text surface? Is it facing the recipient rather than the camera? |
| `location` | Desk, hand, snow, sleeve, doorway, or another exact place? |
| `actionPhase` | Before contact, during transfer, after transfer, wet/damaged, or stored? |
| `bodyFacing` / `gazeTarget` | Where is each actor's torso and gaze directed? |

不要从"接受屈辱"这样的情绪短语或"看着文书"这样的视线短语推断 `holder`。把物理动作写明。

### Paper handling：默认纸张规则

- **携带 / 交接 / 抛掷 / 收纳**：纸保持合拢、折叠或折叠成明确的一叠；封面/文字面随持有者→接收者的方向，而非镜头。
- **阅读 / 查验**：只打开动作需要的那一页；文字方向朝向读者眼睛。绝不要为让画面可读而把纸镜像或旋转。
- **书写**：只有演员确实在写时，纸才能平放；书写方向朝向演员，不是镜头。
- **特写可读**：可读的插入镜头是有意例外。保留读者朝向与真实页序，不能把若干无关页铺成展开式样张。
- **损坏连续性**：一旦道具被揉皱、浸湿、撕裂、折叠、封印或染污，之后每个镜头都继承这一状态，直到一个明确的动作改变。不要让参考图把损坏道具悄悄还原。
- **已有文字**：保留已批准的封面、封印、排版与文字。告诉模型保留已有画面与方向，不要发明新字。

### Furniture & doors：家具与门的站位规则

用已批准的场景图作为空间真值。把工作演员放在桌子、台面或桌子的工作侧——不要放在房间中央、家具与门之间。让门、门槛和离场通道可见且畅通。

书桌→门的动作：

1. 把桌子和它的道具锁在画面一侧。
2. 演员站在桌子的内侧/工作侧，朝向工作面，处于起始状态。
3. 预留从工作侧到门的连续通道。
4. 来访者放在门槛或工作区外。
5. 显式描写转向/到门的路线与返回路线。
6. 核对演员的躯干、脚与视线是否支持起始动作；只是"靠近桌子"不等于"在桌前工作"。

屏风/门场景，指定哪边是内、哪边是外、演员如何进入或躲藏、如何返回动作轴。不要因为一个镜头用了门廊变体就新增正式场景码；保持 CSV 的唯一 `scene_code` 作为场景身份，除非源明确定义了另一场景。

### Prompt construction：提示词写法

把物理状态放进 `paperHandling` 这样的专门 metadata 字段，并在 prompt 中复述动作关键部分。分离：

- **参考职责**：身份、家具、道具设计；
- **物理状态**：折叠/打开/湿/皱与持有者；
- **空间关系**：谁面朝谁、谁能读到表面、路线在哪；
- **动作阶段**：交接前/中/后。

同时写 `metadata.prompt` 和 `metadata.composerContent`。改连续性规则时不要写 `position`、`x`、`y`、`width`、`height` 或布局快照。

### Temporal storyboard continuity：时序分镜连续性

（简要指向）相邻镜头需要保留前一张已接受的分镜作为连续参考时，详见 [references/prevention-by-construction.md](../references/prevention-by-construction.md) 的对应小节（含「事前防范」与「分镜装配」）。

### Verification and repair：核对与返修

（简要指向）按源 CSV → manifest → 画布节点 → 任务/日志 → 真实媒体五层顺序逐级核对；图像与源冲突时按"源错→修复源/manifest / manifest 漏→补 prompt / 参考或工作流错→修绑定 / 模型错→换幂等键"分类处置。完整流程见 [references/prevention-by-construction.md](../references/prevention-by-construction.md)。

## 对话镜头

对话默认设计为单人正反打：每镜只拍说话者或听者一人，景别选中近景、近景或特写，写明视线朝向画外对方的哪一侧。面部角度由镜头情绪、表演和构图需要灵活决定，不固定为三分之二侧脸。机位固定或只做极轻微推近，始终保持已确认的 180° 轴线；不安排两人正面并排站着念词。

- 大段连续台词可在说话者单人镜头与听者单人反应镜头之间切换；按语义转折、停顿和听者的可见反应选切点，不按每句话机械切镜。一人一句的普通正反打默认各自独立成镜、独立成 Clip。
- 听者镜头中台词可由说话者画外延续；在镜头表标明说话人、画外声音的起止范围和听者的具体反应，不能把台词误分配给听者。
- 正反两个方向保持固定屏幕方位和相接的视线；回到说话者时承接其上一镜的姿态与情绪变化。
- 只有掌掴、递交、抓袖等动作必须同时看见双方，才设计双人同框镜头；在文字分镜表中写明同框的动作理由及起止状态。

## 文字分镜表

镜头设计写入制作目录的 `storyboard.md`，一行一镜，按剧情顺序排列；该文件是文字版分镜表，不在本阶段创建分镜图有序组。每镜至少写清：

```text
镜头 ID / 所属段 / 时间范围 / 叙事功能
上一镜结束状态 → 本镜开始状态 → 可见动作 → 本镜结束状态
人物、情绪、视线与手部变化
相机位置 / 景别 / 焦段 / 运动 / 轴线
人物、道具与家具的固定关系
静态关键帧应冻结的唯一状态（默认本镜动作起点）
台词 / 表演节奏 / 环境声 / 动作音 / BGM
所需参考图及唯一职责 / 服装版本 / 色卡 HEX
关键帧策略（新生成 / 复用已验收帧 / 不单独生成）及依据
Clip 归属（默认独立 / 特例合并）/ 合并依据 / 组内镜头顺序与切镜点
下一镜承接 / 失败条件
```

逐镜分析是否真的需要新图：相邻镜头保持同一场景、人物、服装与道具状态，机位和轴线接近时，后镜可复用已有锚点或不单独生成分镜图；这只决定图片策略，不自动改变 Clip 数量。默认每个文字分镜独立生成一段视频。只有两镜间存在明显动作衔接（如同一动作路径跨切点继续），或对白/画外音必须跨镜连续时，才在表中写明合并依据、Clip 归属和切镜点，让 H3 片内切镜。一人一句的普通正反打默认分成两段。场景、人物或造型改变，关键道具状态/空间关系难以从现有参考读出，或新机位与动作起点必须精确锁定时，再为该镜生成独立关键帧。不要为了每个文字镜头都有一张图而生成近乎重复的图片。

## 逐镜参考计划

- 不大幅转身、换方向或做复杂全身动作时，使用最小人物身份参考。
- 全身站位、家具关系、动作路线或轴线重要时使用已确认站位图。
- 站位图已充分说明空间时可省场景图；需要锁材质、家具或灯位时再加场景锚。
- 对话的正反打分别准备单人 16:9 关键帧；动作需要双人同框时才为该动作准备双人帧。
- 上一镜关键帧只有在已视觉验收且确实继承同一人物、道具或空间状态时才可作为连续参考。

## 设计验收与完成闸门

镜头表由本 Skill 自行审查，不另交验收 Skill。逐镜对照剧情段、资产版本、站位覆盖和连续性台账；发现问题时只回修镜头设计或明确退回哪个上游，不生成图片来掩盖设计缺口。

- 所有镜头的时间总和与段时长一致，关键动作有足够执行时间。
- 相邻镜头的结束/开始状态能对接，人物不会跳位，道具不会无因改变。
- 空镜有完整离场因果，正反打有稳定轴线和视线。
- 对话镜头均已核对单人景别、符合当前表演的面部角度、视线方向、固定机位或极轻微推近及 180° 轴线；双人同框有必须同时可见的动作理由，大段画外台词归属和切镜位置清楚。
- 每镜的静帧状态、动态动作链和声音字段已分离。
- 逐镜参考计划没有无关人物、错误时代服装、未通过站位图或未验收的连续参考。
- 每镜有关键帧策略及依据；每个 Clip 默认只对应一镜，合并镜头已注明明显动作/对白衔接依据、组内顺序与切镜点，关键状态变化有足够参考或文字约束。
- 使用 `accepted / needs-redo / waiting-user / blocked-upstream` 记录设计结论；只有 `accepted` 镜头进入关键帧阶段。
- 文字分镜表已写入 `storyboard.md`；在 `progress.md` 记录当前版本、已确认镜头数与下一镜。
- 镜头表与参考计划已确认后才转入关键帧阶段；本 Skill 不提交生成。

镜头表涉及文字道具物理状态时见 [内嵌 § 道具与空间约束]，需要圣经化事前防范时见 [references/prevention-by-construction.md](../../references/prevention-by-construction.md)；分镜图设计见 [references/storyboard-design.md](../../references/storyboard-design.md)。
