# 剧情设计

## 输入与边界

读取用户原文、项目制作目录中的 `progress.md`、`script.md` 和画布现有文本计划。保留用户明确要求的情节、逐字台词、人物关系、时代与结局；未经允许不改台词、不补写关键剧情、不把短片扩成长篇。

先确认本轮是仅整理剧情、允许改编，还是要直接形成生产段。用户要求“只设计”“不要运行”时，本阶段不得创建生成任务。

## 工作内容

1. 写出一句话冲突与本轮情绪目标。
2. 按剧情转折、空间变化和动作闭环划分生产段；段长服从用户总时长与目标模型，不机械平均。
3. 每段记录开场状态、触发事件、人物行动、情绪变化、结束状态和下一段承接。
4. 分离画面、台词、表演与声音：台词保留逐字稿；语速、音量、停顿、呼吸和哭腔等另列；环境声、动作音、BGM 要求另列。
5. 建立连续性台账：角色位置、服装时代、持有道具、道具物理状态、场景时间、门窗/隔断状态和必须延续的曝光。
6. 标记必须通过画面表达的剧情信息，以及只能靠台词/声音表达的信息，避免后续把抽象剧情硬塞进单张静帧。

## 产出格式

```text
项目范围 / 总时长 / 画幅 / 风格
不可改动项 / 允许调整项 / 禁止项

段 ID / 目标时长 / 地点与时间
开场状态 → 触发事件 → 主要行动 → 结束状态
人物目标与情绪台阶
逐字台词
表演节奏
环境声 / 动作音 / BGM
连续性继承 / 下一段钩子
所需角色、场景、道具与特殊空间关系
```

## 完成闸门

- 总时长与各段目标可执行，没有同一动作在相邻段重复起步。
- 空镜、离场、转身、追出、关门等结果都有前序动作因果。
- 每句台词有说话人，画外音与画内对白已区分。
- 资产需求与特殊空间关系已列出，但未替资产阶段擅自生成具体参考图。

完成后将剧本和逐字台词写入 `script.md`，在 `progress.md` 登记版本、段数、时长、资产需求和验收状态，转入资产准备与站位/色彩基准。

涉及多段项目事前连续性架构时见 [references/prevention-by-construction.md](../../references/prevention-by-construction.md)。
