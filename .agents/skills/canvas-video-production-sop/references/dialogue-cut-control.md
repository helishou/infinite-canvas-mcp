# 台词与切镜控制

## 一 · 默认禁止生成内台词跨镜

默认每句完整台词在同一个单镜 H3 Clip 内说完，不让同一句台词跨 `[Shot N]`，不因对白/画外音连续而合并 Clip。优先在完整句结束或已有自然停顿处安排镜头；逐字保留原台词，不为迁就切点删改台词，也不将一句台词拆成多次独立生成。只有用户明确要求跨镜并接受切点不确定性，才作为例外记录。

H3 时间戳、`CUT TO:`、词语锚点都是生成意图，不是精确切镜保证；不得靠反复叠加约束宣称可锁定某秒或某字。目标切点与成片实测切点分开记录，没有实测就写待核对。

## 二 · 必须连续对白时的后期方案

若用户明确要求一句话覆盖多个画面，优先规划“完整原生对白底片＋独立听者反应镜头＋后期只切画面”：

1. 说话者单镜完整说完台词，保留连续原生音轨和同步口型。
2. 听者反应镜头独立生成，只描述倾听与具体反应，不重复生成同一句对白，不把台词分配给听者。
3. 剪辑保持说话者音轨连续，仅插入反应画面；切回说话者用底片对应时刻画面，保持原音画同步。
4. 在镜头表区分生成 Clip 与最终剪辑镜头，记录对白底片、反应素材和计划切点。后期操作须用户授权，不因本规则自动执行拼接、配音或导出。

这是制作策略，不是已验证的 H3 自动能力；默认生成仍只做技术性收口，质量检查仅按用户要求执行。
