# 成片回看清单

用途：用户看完一集成片后，**按这张表逐 Clip 勾一遍，再汇总成一整轮返修**。文件名建议 `<项目根>/.agentproblem/回看清单-<集号>.md`，问题条目仍写进同目录的[问题记录](rework-log-template.md)。

## 为什么需要这张表

过去是用户自由看片、边看边说，结果是**一次回看只收得出一部分问题**：EP2 那集先报 11 项，接着又冒出第二轮（猪/朝向/断喝/去重）、第三轮（反应镜/空镜）、第四轮（连续性/表演）、第五轮（尾帧方案），一天走了 232 次 revision 仍没生成一段视频。

七类逐项过，比凭印象看一遍收得全。**同一轮里收全，比看得快重要。**

## 铁律

1. **先看完，再动源稿**。回看期间只登记，不边看边改——边改会让后续 Clip 的基线不断变化，越改越乱。
2. **一条问题绑一个稳定 ID**（`segmentId` / `shotId`），按画布列表序号说事时同时写 ID，避免序号对不上。
3. **每类逐 Clip 勾**，勾不出问题也要留痕（否则下一轮不知道是"没看"还是"看过没问题"）。
4. 勾完按严重度分两批：**必改**（错事实/错方向/物理错）与**可改**（景别分布、表演力度）。必改在本轮一次做完。

## 七类核对项

### ① 身份与造型
- [ ] 同一角色跨 Clip 的脸型、发型、年龄感一致，没有与旁边角色同化
- [ ] 服装、配饰、伤势状态与前一镜尾态一致
- [ ] 群众/群像角色没有被主角"污染"

> EP2 实例：clip2 侍女面孔与慕璃同化。

### ② 站位与空间（历史最高发，占 6/11）
- [ ] 每 Clip 首镜的 `characters[].position` 与上一 Clip 尾态一致（画内左右是结构化字段；位置类事实以账本为准——先查 `continuityFactIds` 有没有勾、`value_descriptions` 有没有描述，再怀疑提示词）
- [ ] **动线方向**对：从该进的入口进、经过该经过的地标（不是"从庙门涌进"）
- [ ] **分区对**：在案左／供桌侧地面／庙前高台，而不是"对面""旁边"
- [ ] **接触面对**：站地面／台阶／座上，没有站上桌子、没有悬空
- [ ] 视线与朝向：面向该面向的人／声源，背对镜头时面部朝向也写明
- [ ] 没有越轴导致的背景镜像翻转

> EP2 实例：行进方向、供桌朝向、站位漂移、走错侧、站上供桌、朝向背对声源——六条。

### ③ 景别与构图
- [ ] 中景（MS）没有堆叠，近景/特写有足够占比
- [ ] 情绪点有对应景别（该近不近 = 表演白给）
- [ ] 有建立空间的全景/远景，不是全程半身
- [ ] 焦点落在该落的主体上，背景虚化/柔焦符合已定基调
- [ ] 没有影响阅读的裁切（该看见的手/脚/道具不在画外）

> EP2 实例：近景过少、中景过多、全片缺浅景深。

### ④ 台词与时长
- [ ] 每句台词都说完才切，没有被截断
- [ ] 语速像人说话，不是赶场
- [ ] 台词一字未改（对照确认版剧本）
- [ ] 说话人在说话镜里，听者反应镜不抢台词

> EP2 实例：clip10 台词未说完即切走。

### ⑤ 物理与道具
- [ ] 重力、浮沉、惯性、碰撞结果合理
- [ ] 道具状态连续（数量、开启/损坏、持有者、位置）
- [ ] 道具没有被冻结在"全程不变"的状态里

> EP2 实例：金猪掷河后浮在水面，应下沉。

### ⑥ 声音与 delivery
- [ ] 情绪强度对（该断喝的不能软、该低声的不能喊）
- [ ] 音色跨 Clip 一致
- [ ] 无 BGM／无字幕／无包装（除非本项目已确认要）
- [ ] 没有与画面打架的声音描写

> EP2 实例：「够了。」delivery 过软。

### ⑦ 连续性与尾态
- [ ] 每 Clip 首帧接得上前一 Clip 尾帧
- [ ] 动作进度没有被重置（不是每次都从头开始）
- [ ] 段落切点落在自然处，不是话说一半
- [ ] 上一段的问题没有复发（对照问题记录里仍 open 的条目）

## 汇总格式

勾完后按下面结构交给用户确认，再动源稿：

```text
本轮共 N 项：必改 A 项 / 可改 B 项
① 身份：无
② 站位：clip3 供桌朝向反了（必改）｜clip16 站上供桌（必改）
③ 景别：全集 MS 占 46%，CU+MCU 仅 12%（可改，建议加 4 个反应近景）
...
建议返修顺序：（先改错事实，再改分布与力度；同一批 ops 提交）
```

## 与阶段推进的关系

回看验收属于阶段 ⑥（Clip 视频）内的返修，不推进阶段。整集回看通过后，才把 `clips` 记入 `done`（见[制作阶段与推进顺序](../references/production-stage-order.md)）。
