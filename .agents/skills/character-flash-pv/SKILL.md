# 人物快闪 PV

按用户当前要求进入相应阶段，完成有证据的交付。用户当次要求覆盖项目默认值；参考分工、媒体归档和真实任务状态必须保持可追溯。

## 先确定范围与默认值

- 仅讨论/策划/写提示词：交付方案，不保存画布、不生成、不发布，除非用户另有授权。
- 新项目完整制作：新建独立自由画布，不建立剧目、分集或 Acheng 正式制作稿；按下表顺序制作。完整制作授权包含必要资产与 Clip 生成，发布仍以明确发布请求为准。
- 续做/返修/仅超分/仅发布：先定位已有画布、原任务、资产或最新剪映草稿，只补缺失或指定阶段，不重建项目、不重跑成功任务。
- 未指定规格直接采用默认值，不逐项询问。只有显式要求互相冲突、明确指定的生成总时长不是 5 的整数倍或必要模型无法唯一映射等阻塞项才提问；同时继续独立工作。

| 项目 | 默认值（用户当次要求可覆盖） |
|---|---|
| H3 源素材 | 8 个独立 Clip，每段 5 秒，共 40 秒；其他总时长按总时长÷5 得到 N |
| 镜头 | 每 Clip 5 镜、每镜约 1 秒、硬切；用户指定镜数时保留。实际选镜与成片时长以可用镜头和踩点剪辑为准，不硬凑 40 秒 |
| 画幅与生成尺寸 | `9:16 (Portrait Widescreen)`、显式 `megapixels: 2`；保存值、预检生效值、实际归档尺寸分别核验 |
| 连续性 | 关闭 Motion Context、AV latent、tail-frame continuation；每段提示词自足 |
| LoRA | 丝袜质感，强度 0.5；先查当前目录精确映射，缺失不静默替换 |
| 超分 | 先选镜；生成期 H3 二采与已有草稿的 FlashVSR+ Turbo、2× 分开，按阶段参考选择，不自动叠加 |
| 成片 | 剪映踩点、变速、调色美颜、水印、音乐收尾，由用户在剪映导出 |
| 水印 | 慢速飘动、半透明文字「热王小鸟鸟」 |
| 平台 | YouTube、B站、抖音、视频号；默认平台不代表已获发布授权 |

## 导演设计先于分段

先用一句话定下展示主题与不超过 3 个角色记忆关键词，再按[镜头模板 §0.4–0.7](references/flash-shot-template.md)设计整片：视觉爆点→容貌侧影→全身空间→动态身份细节→情绪收束。五镜/六镜是整片功能结构，不是每个 5 秒 Clip 都重复一遍；优先用景别交替、动势匹配和真实音乐重音组织素材。

10–20 秒是紧凑成片的常用设计区间，不自动改写 8×5 秒源素材默认值，也不截短用户锁定的成片。用户指定成片长度时按剪辑目标处理；只有明确指定生成总时长时才按 5 秒分段，不要求 18 秒成片改成 20 秒。独立 Clip 之间可以剪出方向承接，不因此开启上下文接续。声音与材质运动必须对应可见动作，不能靠静图缩放和音效堆叠代替角色表演。

## 执行顺序与阶段完成条件

进入某阶段前读取该行指引，避免一次加载所有参考。复用现有回执、镜头清单和草稿记录交接证据，不新增审批或并行维护另一份业务状态。恢复时核对当前目标是否变化；输入未变的有效证据直接复用。

## 全程保持的边界

- 画布持久编辑遵守[画布数据契约](../../rules/canvas-contracts.md)，使用原生 MCP/受支持入口，不直写数据库或绕开 Backend 提交画布生成。
- 模型用当前目录精确 ID；用户指定模型不支持或失败时保留成功输入，说明阻塞，不静默换模型。不修改全局默认值，不用近似含义参数冒充指定值。
- 参考图身份、服装/体态、环境的职责分开；图1/图2与 Picture 顺序以实际 manifest/绑定为准，不声称传入未传的参考。
- 视频归档后执行选镜→超分→剪映。ffmpeg/CLI render 产物是代理预览；只有用户明确要求不用剪映直接给 MP4 才走直出版，并标注「未经剪映」。待用户导出时交付可审阅草稿与剩余步骤，不宣称成片已导出。
- 已获授权的超分先探测实例及队列；离线时可启动所需实例，健康后提交。后台顺序处理并继续独立准备，不中断在途任务、不重启或关闭其他服务。仅本快闪流程允许备份并读取最新草稿后关闭剪映编辑，完成后重新打开。
- 任务等待/恢复时读[生产任务](../canvas-video-production-sop/references/canvas-production-runs.md)与[原生调度纪律](../canvas-video-production-sop/references/native-mcp-operation-budget.md)。结果未知先查原任务；不盲重提、不绕过预检 hash、不自动取消占用任务。
- [编排预算](references/orchestration-budget.md)用于合并读取、批量等待和降采样；不能省掉身份、场景、选镜、封面的必要视觉验收。任务成功、尺寸正确不代表内容通过。
- 发布文案默认不挂 AI 标签，平台强制声明照实填写，不声称实拍。发布工具缺失或待登录时保留发布包、报告具体阻塞，不索要凭据或全局安装工具。
- 用户纠正立即落实到当前任务；仅在明确要求维护 Skill 或确认可复用指令缺陷时更新技能，避免积累一次性例外。

## 交付回执

只报告本次范围内的已验证结果。用紧凑清单给出画布与资产定位、Clip 数及实际规格、镜头清单、超分输入/模式/输出、剪映草稿与导出状态、文件路径及精确阻塞。技术明细留在对应产物，不每轮重复整套验收表。

严格区分已保存、已提交、已归档、已审看、草稿已验证、待用户导出和各平台发布状态。发布已收到成功回执但后台未核对时如实分别标注，不把待核对说成发布失败或重新发布。

维护后用 [行为验收用例](references/behavior-checks.md) 检查执行决策；不以复述规则代替遵循，也不为测试触发真实生成或发布。
