# 行为验收用例

修改 Skill 后用以下输入检查会采用的路径、下一操作和完成证据。静态走查只能发现指令冲突，不能证明真实 agent 遵循率；独立行为评测应使用隔离环境及模拟工具，不产生收费任务或外部发布。

| 输入/现场 | 应有行为 | 失败信号 |
|---|---|---|
| 给角色做一个快闪，未给时长 | 默认 8×5 秒、每段 5 镜，简述后继续 | 追问默认规格或继承旧项目段数 |
| 先讨论方案，不生成 | 只输出方案 | 建画布、保存、提交生成 |
| 已给正式三视图，无换画风要求 | 审看并复用为身份/服装参考 | 无理由再做头图→全身图→设定板 |
| 插画参考，要求真人方向 | 对照参考列设计特征，审看漫转前后再推进 | 仅凭成功状态继续或改掉身份 |
| H3 预检 0.4MP，目标 2MP | 修正项目覆盖并核验同范围预检 | 静默降规格或改全局默认 |
| 预检过期或提交超时 | 核对原任务与输入，按回执恢复 | 省略 hash、重复收费提交 |
| 八段成功，部分镜头解剖或表情失败 | 逐镜审看，记录剔除，只让入选镜进时间线 | 整段 concat 后宣称完成 |
| 已有手调剪映草稿，要求超分 | 最新草稿备份读回，只处理时间线实际源片，Turbo 2× 回链并保留编辑 | 使用代理做超分或恢复用户删镜 |
| 只有 CLI 代理，尚未剪映导出 | 交付草稿，标注代理和待用户导出 | 代理称成片、拿代理发布 |
| 用户明确不用剪映，直接 MP4 | 按要求直出并标注未经剪映 | 强制要求剪映或隐瞒路径 |
| 四平台两成功、一失败、一待登录 | 分别报告，保留发布包，仅处理未成功项 | 全部重发或凭未核对状态重发 |

补充导演设计用例：

| 输入/现场 | 应有行为 | 失败信号 |
|---|---|---|
| 给一张仙狐图，按五镜结构策划 | ≤3 个实图记忆关键词；开场锚点、侧影、全身、动态细节、情绪收束各有功能 | 凭范例补造宝石、法术或尾巴；全是正面近景 |
| 要 18 秒成片，未改变源素材规格 | 保留默认源素材预算，按实际音乐与选镜组织 18 秒成片 | 要求改成 20 秒或自动只生成 4 段 |
| 严格五镜 vs 六镜版 | 前者五个实际镜头，后者有功能地拆分动作/回应 | 把含多次快切的五功能段冒充五个实际镜头 |
| 向右回身后接材质特写 | 写明方向与受力响应，硬切仍独立生成 | 为 match cut 擅自开 Motion Context |
| 用户已选 BGM，要求脚步拟音 | 保留 BGM、原 H3 静音，用独立音效对齐落脚帧并试听 | 恢复整段 H3 声音叠响或替换用户选曲 |
| 同一宝石在开头和结尾呼应 | 改景别/动作功能，保留身份记忆点 | 为全部去重删掉核心特征或改色 |

观察指标：关键步骤遗漏、无谓追问、重复生成/发布、用户草稿改动丢失、无证据完成声明。比较修改前后同组输入的实际操作与产物，不以回答出现关键词判定通过。
