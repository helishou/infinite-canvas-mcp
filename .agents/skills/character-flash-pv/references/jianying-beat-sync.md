# 剪映成片踩点重音剪辑（JianYing 5.9 草稿）

适用：Clip 导出/拼接后在剪映做快闪踩点重音成片，或对已有剪映草稿对齐重音、加淡出。CLI、draft schema、编辑器生命周期见 Hermes 侧 `capcut-edit` skill。

## 用户硬规则（违反会被当场纠正）

1. **素材内容一帧都不裁**——时长压力全部靠变速解决。
2. 变速范围克制：**加速上限 ~1.45×**（≥2× 被明确否决为"太多"）；氛围镜（行走/特写）可轻度慢速 0.65–0.9×；**高潮镜不许慢速蓄力**（慢速蓄力被否决），高潮用正常速收刀落在最强锤上。
3. **同一镜头不许在连续动作中被拆成不同速度的两段**——会被看成"同一个动作重复了两遍"。同镜跨拍要么整段一速（拍点在镜内不切），要么只在锤点做 ±0.2 内的轻 ramp。
4. **切点必须落在明显重音上**（spectral-flux 强度 ≥400 量级），弱前奏轻点不切；长镜跨过强锤会被质问。
5. **镜头长短按鼓点间隔分配**：密集连拍给短切片/快切镜（手部、双足等细节镜），宽间隔给主镜。开场放定场长镜，细节特写放中段快切位。
6. 用户手动改过草稿后：**顺序绝对不动**，只移动时间线边界+调速来吸附重音；用户手设 1.0× 的段会把相邻切点锁死，动之前先问。改坏了用 `draft_content.json.bak` 还原。
7. 音乐默认采用**重音＋短余韵**：末镜切入落在清晰重音，保留短暂冲击，再让短混响或回声淡出；根据实际音乐与画面调整长度，不把单纯全曲渐弱当作默认。用户指定其他收尾时从其要求。

## 流程

1. 修改快闪草稿前核对目标与最新落盘内容，并备份草稿。用户已授权：剪映仍在运行时，自行关闭对应剪映进程（`Stop-Process -Name JianYingPro`），不再要求用户手动退出或重复确认；关闭后重读草稿，以最终落盘内容为修改基线。若仍有进程占用或落盘发生冲突，先定位原因，不用 `--force-write` 绕过。完成修改和回读验证后重新打开剪映。此授权仅适用于本流程的剪映草稿编辑，不扩展到其他应用或服务。
2. 重音检测：BGM 转 wav → numpy 谱通量（frame 1024/hop 256、Hanning、[1,2,3,2,1] 平滑、24 帧移动均值 +0.35 delta 阈值），取局部峰、强度 ≥400 为"必须切"的重音，边界吸附到 30fps 网格 `round(t*30)/30`。
3. 对每段：`target_timerange` 边界吸附到最近重音（±0.45s、单调、gap ≥0.35），`speed = srcDur/tgtDur` 写进段引用的 speed material（`curve_speed: null`）。源边界必须是整数源帧（24fps 素材用 `round(sec*24)/24`，否则切点有一帧上一场景残留）。
4. 预览验证：手写 ffmpeg trim/setpts/concat 图（不用 CLI render），灰度 rawvideo 逐帧像素差找切点峰（scdet 对相似画面不敏感）；预览 ±1–3f 偏差是 24→30fps 转采样噪声，JSON 才是真值。
5. 收尾默认先找末镜重音并保留其冲击，随后加入短余韵并淡出；先试听、核对画面与音乐，不能未分离音轨就声称独立去掉鼓点或只留下旋律。处理后音频另存，保留原曲以便恢复，避免原音轨和处理音轨叠响；用户指定其他音乐收尾时，以当次要求为准。
6. 重开剪映，让用户手动导出（用户偏好手动导出，CLI render 只出代理预览且每段从 0 trim，不可用于正式成片）。导出前在剪映页面核对浮动水印的透明度与漂移，导出后从成片抽帧做封面。

## 浮动水印（每条快闪片默认加）

**规格固定**：文字「热王小鸟鸟」，半透明，慢速飘动，覆盖全片。

- **透明度**：段级 alpha 0.22–0.35（默认 ~0.28），按背景明暗微调；亮背景靠低透明阴影/描边保可读，但不能抢主体、不能出现实心白块。`materials.texts[].text_alpha` 与段级 `clip.alpha` 要一起落到同一个值，只改一处会出现“数据是半透明、画面是全白”。
- **漂移**：位置关键帧 `KFTypePositionX` / `KFTypePositionY`，`curveType:"Line"` 匀速，不加缓动、弹性、旋转和缩放。一个完整来回 ≥12 秒，单程位移不超过画面宽 8–10%（归一化坐标 ≤0.15），相邻关键帧时间差一致，避免忽快忽慢或到边界急停。
- **全片覆盖**：一条**独立文字轨道**，从 0 覆盖到成片末尾（含淡出段），不逐镜复制、不挂在字幕轨上（字幕轨会被自动识别/模板改写）。文字段 `render_index` 高于视频段，不被滤镜或遮罩轨道盖住。
- **短片持续运动**：首末位置关键帧放在文字段的首尾；短于一个漂移周期时保持单程匀速，不在镜内停顿或折返。不能仅凭存在关键帧就宣称浮动完成；须检查开头、中间、结尾位置持续变化，位移应在正常播放下可辨，并以剪映实际播放或原生导出样片验收。
- **安全区**：避开右下角平台文案与进度、右侧点赞/评论按钮列、顶部标题区；不压眼睛和嘴。默认在画面上部或左下的空白区域飘动，人物主体居中时优先上部。
- **实现要点**：文字素材字段是 `materials.texts[]`（`content` 是 JSON 字符串，含 `text` 与 `styles[].size`），段级位置动画走 `segments[].common_keyframes[{property_type, keyframe_list:[{time_offset, values, curveType}]}]`，坐标是半画布单位 `[-1,1]`。`time_offset` 相对段起点还是绝对时间线，先在样片上用小段核对，不靠猜；写完回读确认关键帧覆盖整段而不是被夹在首尾。
- **只在剪辑层加**：水印不写进 H3 提示词，也不让视频模型“生成文字水印”。模型会把中文字画歪、还会随镜头一起运动，且无法控制透明度与周期；H3 侧继续保留“不要字幕/文字/水印”的约束。
- **已有水印不叠加**：草稿里已有同文案水印时按用户当次要求处理，不重复加第二层。
- **验收**：文件回读只能证明字段写入。必须在剪映实际页面看透明度与飘动，再导出 2–3 秒样片抽帧对比两三个时间点的位置，确认“慢、淡、一直在动且不挡脸”。代理预览不能复现的差异如实说明。

## 穿帮打码（纯 CLI 方案）

剪映"局部马赛克"资源本机没缓存时，用已缓存的「模糊」场景特效（resource_id `6739752823140913675`，effect_id `634025`，在 `Cache/effect/634025`）代替：
1. `capcut duplicate <proj> <seg> --new-track` 复制穿帮段到上层轨道；
2. JSON 把复制段 `source_timerange` 裁到穿帮窗口（整数源帧）、`target_timerange` 按原速度换算回时间线位置；
3. `capcut mask <proj> <dup> rectangle --center-x --center-y --size --rect-width --round-corner 60 --feather 25`（坐标是半画布单位 [-1,1]：`x/画布宽*2-1`；size 为画布高占比）；重设要先 `--off` 再 apply（同段只允许一个 mask）；
4. `capcut add-effect "模糊" <start> <dur> --bind <dup> --resource-id ...` 实际会建独立特效轨道——要段级贴法：删掉它建的 effect track 段，把返回的 material id 直接 append 进复制段的 `extra_material_refs`（material 存在 `materials.video_effects`，段级引用即剪映的段效果）。
5. 遮罩范围宁大勿小：以检测框外扩 30–80px；用 ffmpeg boxblur 近似渲预览验证覆盖，逐帧像素差证明补丁每帧生效。

## BGM 选择（用户授权自己找）

- 找**重音密度高的 remix 版**。基线参考：客官不可以 remix `cbed8462…mp3`，15.3s，~94BPM 双拍，重音间隔 0.63s，top 锤强度 566。判定：谱通量重音 ≥400 的个数 ≥ 每 1.5s 一个才算"够炸"。
- 剪映音乐库定位法：`key_value.json` 的 searchKeyword/materialName → `downLoadcfg` → `Cache/music/<hash>.mp3` → faster-whisper 转首 45s 对歌词。候选不足时用本地 chatgpt2api 搜"歌名 remix 高潮版"，让用户先导入到剪映音乐库再取缓存文件。
- BGM 从爆点段起播（前奏弱铺垫段不要），整曲铺满时长优先于切尾；切尾只用作压缩总长的最后手段。

## 封面：从成片里取全片最强高光帧

用户 2026-10-29 明确否决“无脑截首帧”：**封面必须是全片最有冲击力的那一帧**，不是第一帧，也不是平台自动截的那张。

1. **候选来源**：复用本文件流程第 2 步的谱通量结果，取强度最高的 3–5 个锤点（≥400，含末镜落幅锤）。只在锤点 ±0.2 秒内抽帧，每 1/30 秒一张，单锤点上限 13 张。
2. **从最终成片抽**：用导出的成片（已含调色、美颜、水印），`ffmpeg -ss <t> -i final.mp4 -frames:v 1` 精确抽帧；不要用原始 Clip 或调色前帧冒充，否则封面与视频不一致。
3. **先剔除**：转场混合帧（前后镜叠影）、运动模糊、闭眼或半眨、嘴型过渡帧、字幕/贴纸压脸、水印压脸、主体出画、构图不完整。剔除后仍有候选才进入挑选。
4. **排序标准**：身份清晰（脸和辨识配饰可读）> 势能/表情强度（重音释放瞬间或稳定落幅）> 缩略图尺寸下主体可辨 > 与标题文案匹配。末镜定格若姿态最强可优先，但不是默认答案。
5. **看图纪律**：候选批量降采样到长边 ≤1024 一次看完，不逐张读原图；选定后回**原分辨率 1:1** 复核清晰度和噪点，缩小图看着清楚、原图糊掉是常见坑。
6. **按平台裁切**：抖音/视频号默认 3:4（1080×1440，另可给 4:3 1440×1080）；B站、小红书按当次 `--thumbnail` 要求，至少短边 ≥720。居中裁切，脸放在平台 UI 不遮挡的安全区（避开右下角文案、右侧按钮列）。
7. **落盘命名**：`cover_<平台>_<比例>.jpg`，与成片同目录。交付时报告选中时间点、锤点强度、对应镜号与文件路径，并注明“未使用首帧”。
8. **没有可用高光帧时**（全片都在糊、都在转场、脸一直被挡）先问用户选哪一镜，不静默回退首帧，也不让平台自动截取。
