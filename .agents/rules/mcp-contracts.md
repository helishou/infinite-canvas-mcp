# MCP 工具契约

触发：新增或修改 MCP 工具、共享 schema、插件声明、读写返回或兼容入口。继承[根约定](../../AGENTS.md)；业务事务与数据保护见[画布数据契约](canvas-contracts.md)。工具开发路径见[工程指引](../skills/canvas-h3-implementation/references/mcp-tool-development.md)。

## 返回与完整读取

- 默认读取返回身份、版本、状态、数量和可执行的详情读取入口。正文、参考集合、历史结果、完整模型目录或整张画布必须显式读取；不得把完整对象藏在摘要的其他字段中。
- 写工具按操作投影短回执，保留操作身份、revision、重放状态、结果数量、警告代码及读回入口。禁止展开业务完整返回后仅删除某个大字段；提交、幂等和原回执由 Backend 保持，返回体治理不得重新执行操作。响应丢失后恢复原回执须明确标记重放；重复同步同一发布输入，且绑定和顺序已一致时，不新增画布或制作稿版本。
- 大集合提供筛选与分页，长正文提供定向／分块读取，导出提供鉴权文件引用。必须能读取完整内容，不静默截断，不把当前页当全集。分块保留内容摘要，游标绑定读取对象、版本和查询条件；历史游标不能依赖当前草稿版本。
- 超限响应必须给出该工具实际支持的参数或替代工具。沿用当前输出保护，不能通过放大上限或关闭保护掩盖接口缺陷；产品边界调整按根约定取得对应授权。
- 下载引用不含 token 或本机路径；文件按固定内容身份读取并走 Backend 鉴权，不能复用免鉴权媒体路由暴露项目快照。

## 共享与验收

- 工具 schema、描述、插件声明、Backend 注册和 Agent 兼容入口同步；显式参数与默认返回必须一致。复用共享投影与服务，不在每个入口维护独立裁剪逻辑。
- 修改默认契约前检查直接消费方并同步调用参数；文档说明外部调用迁移。Backend 网页接口需要保留完整行为时，由 MCP 显式传递视图，不顺带改变网页默认契约。
- 新工具或返回契约变更必须使用大正文、多条目和历史结果夹具验证：默认返回不夹带完整集合；分页无重复遗漏；分块重组内容与哈希一致；版本变化拒绝旧游标；写回执能重放且不重复执行。
- 验证实际 tools/list 与 tools/call 的默认及显式行为，覆盖本次受影响的共享 HTTP MCP、插件和 Agent 兼容入口。记录同一任务的总 UTF-8 返回字节数、调用次数和耗时，不能只用单次变小证明收益。
- 收口区分源码已写、共享产物已构建、进程已加载和行为已验收；保留历史埋点，不删除旧峰值制造改善。
