+ 工作流列表双击重命名：在「工作流管理」页面的工作流列表里双击某条标题，应变成输入框，输入新名称回车或点击别处即保存；列表标题与（若已打开）详情页标题更新为新手名字，底层文件名不变；空名称或与原名相同不触发请求。
