# 待测试

## 局部分镜返修与模型提示词

- 定向替换一个场次的分镜，保留原 Segment ID 和场次起止帧。检查版本冲突拒绝、操作重放、跨场保护及对白和参考时间窗更新。
- 新 H3 提示词明确局部 Shot 时间窗，身份与参考事实去重，画外声不追加可见口型要求。用实际视频检查隐藏观察者、延迟出场和真蛋吞入；结构通过不代表视觉通过。
- Clip-only 编译在 keyframePolicy 为 none 时排除未使用的分镜帧资产；显式请求关键帧仍完整校验。
- 准备草稿场次的全部 Clip 会修复物理时间线顺序，无需发布或生成，保留历史结果和非正式 Clip 的槽位。检查倒地先于解释、解释先于收尾及重复准备。

## Motion Context 默认与边界判定

- 尾帧参考与 Motion Context 互斥：界面启用一个会保存另一个为关闭；正式源稿双开时编译、发布和生成预检拒绝，直接投影也拒绝。诊断定位到相邻段；历史冲突值保留，等待明确修正，不静默改选。

- 新建 H3 节点、添加或复制 Clip 默认关闭 Motion Context 与尾帧参考，不继承保存的全局续写默认；已有 Clip 的显式选择保留。检查旧默认设为开启后新增 Clip、复制开启的 Clip、刷新与再次读取。
- 导演仅在两段必须保持同一不间断摄影镜头时选择 Motion Context；正常对白正反打、机位变化和全场切镜均可保持关闭。A 段开关登记 A→B，B 段参考 A 的末帧或 AV latent；末段开关不影响自身生成。

## Motion Context 接续组生成

- Motion Context 连起的相邻 Clip 在时间线与参数面板显示接续组范围。从组首点击「生成当前 Clip」自动依次运行全组，到第一个关闭的接续边界停止；组内已完成 Clip 也会重新生成，建立本轮潜变量接续。「运行当前及后续」保留原有更大范围。请检查默认参数继承、开关编辑与刷新、分组边界，以及组内取消和待确认流程。

## Backend 开发热重载

- Backend `dev`／`dev:watch` 默认监听源码和共享 Agent dist，连续修改合并为一次重载；媒体任务、待确认任务、Agent／生产代理回合或写请求活动时等待。空闲后先关闭写入入口，再由旧进程正常退出，重载器只启动自己的 Backend 子进程，不重启 Web／ComfyUI。核对保存后新 PID、忙碌时 PID 不变、任务完成后重载、连接恢复及草稿／回执保留；共享源码需先构建 dist，测试与声明文件不触发重载。语法错误退出后保留监听，下一次源文件修正再启动。生产 start 和单次 dev:once 不启用监听。

## 手动历史结果选用与未发布草稿

- 正式制作批次的历史结果沿原批次提交回执核验，支持单段与多段共用父任务；不要求另有原生节点任务绑定。核对第二场 H3 的批次历史选用、错误节点／Clip／分集拒绝、原批次与任务保持不变，以及旧批次无画布快照时使用原发布版本记录核验。
- 人工选用历史结果统一按当前正式草稿目标执行，无需发布当前稿，不依赖旧任务是否具有新版快照字段；仍核对成功任务、日志、媒体、节点／Clip、活动任务和双 revision。旧发布稿与原任务输入保持不变，旧输入媒体保留变化标记；手动选用不更新旧发布稿。核对草稿已修改、尚无发布稿、重复回执、错误归属及混批回滚。确定拒绝的旧提交经现有“核对服务器修订并保留编辑”流程结束，不自动换 ID 重提。

## 正式 H3 输出选用入口

- 正式 Clip 的输出卡片使用“设为当前输出（保留当前提示词与参数）”，打开与节点历史版本相同的预览核验与选用流程；确认后由正式事务同步制作与画布记录。跨 Clip 输出需先选择对应片段，归档媒体或正式绑定缺失时拒绝，不走普通恢复 ops。普通 H3 的提示词／参数恢复保留原行为。核对取消无写入、成功选用、运行占用、版本冲突和历史输入保留。

## 制作编译阻塞定位与复用

- 编译受阻时显示具体 Segment、Shot、来源字段及命中短语；源稿的外部文字依赖与编译器生成错误分别处理。工具请求完成不再掩盖编译排队、运行、受阻、失败、中断或成功；状态、诊断和目标查询有不同标题，详情保留原操作及是否应用。
- 相同有效输入的可定位源稿独立性阻塞，换操作 ID 返回原回执并明确本次未重跑；参考、范围或引擎改变后允许编译。旧任务不迁移，真实制作稿和媒体不自动修改。核对重启恢复、中英文、主题、诊断分页及 source/compiler 来源。

## 生成任务查询卡片

- 查询成功时按实际返回任务统计数量，不把“失败 0”或列表中的失败任务判成查询失败。实时与历史摘要共用结果解析；真实错误保留原因，连接故障给出恢复后重新查询的提示，缺少列表时不显示假零值。核对中英文、深浅主题、空列表、混合任务状态与真实查询失败。

## 子代理输入与结果

- 左侧预览按上方输入、下方子代理结果连续展示，共用滚动区域；输入从 Backend 保存任务读取委派要求、补充上下文及可展开的冻结工作包，任务运行中也可查看。核对输入／结果顺序、连续滚动、中英文、主题、读取失败，以及切换导演／画布后旧输入和迟到读取不能串入新预览。

## 子代理左侧预览

- 点击子代理任务行在导演面板左侧打开结果、运行状态或失败详情，右侧保留任务列表与对话；再次点击同一任务、关闭按钮或 Esc 可关闭。窗口尺寸变化时重新定位；左侧空间不足时使用视口内预览。切换导演／画布立即隔离旧预览和迟到结果，打开预览不发送或采纳建议。核对中英文、深浅主题和窄窗口。

## 待发送队列折叠

- 点击“待发送”标题可折叠或展开，收起保留条数；队列状态和条数更新保持用户的折叠选择，不影响发送、插入或移除。暂停时“继续队列”仍可使用。核对中英文、深浅主题及窄面板。

## 正式 Clip 续接开关持久化

- 正式制作 Clip 的尾帧参考与潜空间续写修改进入真实保存请求，不再被编译字段过滤。验证当前 Clip 与全局配置下的开启、关闭、互斥切换及刷新；全局选择同步到本节点各 Clip，提示词、引用和编译身份保持原值。

## 对白分镜景别与剪辑

- 新建导演源稿默认采用分镜策略 v1，普通对白优先中近景／近景正反打。每个 Shot 明确景别、观看对象和切入／保持理由；摄影视角切换独立登记镜头，单镜可以短于 4 秒，Clip 仍按 4–12 秒规划。
- 缺少结构字段、对象引用无效或片段内帧窗不闭合时阻止编译；多人中景对白、多人共用一镜和景别正文矛盾仅提示复核，不自动插镜。未声明策略的旧稿保持兼容。
- 核对编译正文保留景别、观看对象、局部镜头编号和对白时间；画面验收另检查实际近景、反打、视线与口型。隔离对照不改正式制作稿，不将编译通过视为画面通过。

## H3 参数展示与真实保存一致

- 潜空间续写预检核对上一段当前成片对应的真实续写任务，缺少时提前返回阻塞，不再把随后必然失败的请求显示为就绪。关闭上一段“传给下一段”后，核对下一段预检及提交前冻结计划不再接入潜变量；预检不创建媒体任务。

- 编辑 Clip 只保存所选字段及必要联动开关，保留其他 Clip 与默认策略，不再把时间轴展示时补出的模型、采样等值写回。核对当前／全局编辑、显式 false／0／null、默认继承与手动覆盖、保存回执、刷新及生成预检。
- 已打开控件随确认的默认参数和重连刷新更新；迟到读取不能覆盖新确认的保存值，读取失败保留现状且不触发旧默认迁移。导出及“设为默认参数”与执行使用同一生效值，导入收到保存确认后才提示成功。
- 可用 `web/tests/h3-state-consistency.html` 独立验证默认变化、Clip 数据保留、保存失败及确认回执值。往返回归覆盖真实前端 diff、临时 Backend 事务、回执 delta 和刷新回读，不提交媒体生成。

## 导演生产编排加固

- 自动图片审核将本地媒体路径交给 API/Codex 渠道适配器；缺图不批准、不重生成。核对真实渠道的图片可见性。
- 正式子任务冻结 draft、范围、依赖、素材摘要及专业合同；主导演核对后通过 `production_edit.adoptions` 原子保存和登记。验证无关场次修改可继续、范围修改拒绝、事务回滚及原 operationId 重放。
- partial 沿原任务与线程续写，历史产物不可变；重启核对全部导演任务，恢复只读取原已完成回合。核对超过十个任务、缺失回合、交互交付暂停与自动模式续写。
- 子代理面板区分待核对、内容未完成、输入过期、已采纳和执行失败，显示产物及采纳修订，并提供原回合读取入口。核对深浅主题、中英文、刷新、重连和会话隔离。执行或技术成功不代表真实媒体验收通过。
- 共同资产与场次自动审核固定专业合同并保存原回合与产物；场次源稿、审核记录的产物与写入修订同事务登记，面板展示对应修订。交互续写必须有 explicit 意图，原模式变化拒绝继续；按钮点击沿原任务续写。真实模型验收使用隔离制作记录与仓库现有图片，不提交媒体生成；人工核对创作质量仍保留。
- 必载专业正文由 Backend 核验并预载，不依赖模型主动打开所有模块。隔离验收已验证原生 Codex 主导演两轮交付与采纳、原回合只读恢复，API/Codex 均识别出测试图片的两个人物、云海和暖光；默认 API 主导演仍只返回文字，工具调用验收未通过，需具备工具调用能力的渠道。程序验收不替代用户创作质量验收。

## 并行制作阻塞交给导演

- 场次失败或受阻、带错误的待审核或暂停工作、共同基础审核错误及请求拒绝在面板顶部集中提示。点击「交给导演处理」沿现有导演入口传入原错误、制作对象、版本、场次及原 workId；普通无错误的待审核保持原语义。核对中英文、深浅主题、目标准确，以及点击交接不直接生成、恢复工作或批准审核。

## 导演对话断线恢复

- 对话连接重建或卸载时立即清除已连接状态；提交被判定发起网页断开后，重新连接并保留原输入，不自动重发任务。核对后台重启及页面离开再返回后的恢复，包括排队任务与附件。

## 制作源稿读取复用

- `production_get` 支持 `ifRevision`：已完整持有同对象、snapshot、视图和范围的内容时，版本未变返回短 `unchanged`，变更后返回新内容。续页不带此参数，旧游标仍拒绝；任务实时状态沿 readiness/run/task 读取。验证共享 HTTP MCP、Agent 兼容入口及中途编辑。
- Agent 和生产 SOP 明确复用已读版本，成功写回执的 `nextRead` 按需使用；已有导演稿优先局部源稿／连续性编辑，由 Backend 重算哈希。验证长任务不再反复整稿读取或对相同候选稿重复计算哈希；没有做真实 Agent 对照运行前，不将接口字节减少视为调用次数已减少。

## 制作编译复用与失败目标恢复

- 未变化且回执、正文摘要和引擎版本有效的编译产物可复用；选定范围内局部修改只编译失效目标及其必要依赖，保留其他产物的原始来源。同一次绑定校验中，同一媒体只读取一次字节摘要，每条绑定仍独立核对归属和声明摘要。核对全量与局部请求、参考文件变化、引擎切换、连续性阻塞和幂等恢复；复用不跳过正式媒体与版本检查。
- Clip 完成判定不再依赖场次并行开关或整批成功：失败批次中的成功片段仍须有对应成功任务、可访问归档、活动绑定及匹配输入。核对只补失败项、旧结果输入变化、人工参数修改、重复同步和 Motion Context 连续组恢复；已完成独立片段不重复提交。
- 新建系统占位 Clip 保存空输入基线，后续有效编译可自动填入提示词和参考；人工编辑与已有无基线内容继续保护。核对先准备后编译、跨场推进、人工改写以及准备/应用重放。技术完成不代表视觉审核通过。

## H3 续段衔接开关互斥

- 同一 Clip 开启尾帧参考或潜空间续写时，自动关闭另一项；主动关闭允许两项均关闭。开关显示与 Backend 保存值保持一致，不通过界面归一化掩盖旧双开状态；旧双开需通过显式编辑真实保存。后端事务同时保存和广播两个字段，重复请求恢复同一回执；续写分组使用同一参数，冲突保存值明确提示修正。核对双向切换、刷新后的保存状态，以及选用其他视频模型时的尾帧开关。

## 大体积 Agent 补充历史与后台连接

- Codex 标准输出按新数据块扫描换行，只在完整消息到达时合并一次，避免长历史响应期间反复扫描完整前缀；按字节分块仍保留中文、emoji 和 CRLF。验证大消息、连续消息和未完成尾部，以及打开长对话期间后台响应。

- 补充历史保持原 JSON 格式与原子替换，保存时逐条序列化并交还事件循环，按流背压写入临时文件；不清理或截断已有历史。验证大历史保存期间健康检查与业务请求可响应，以及并发事件、终态、失败回滚和重启恢复。
- 后台连接失败横幅说明后台可能未启动或正忙，不再把所有连接失败断言为未启动。核对中英文提示与恢复连接后的横幅消失。

## Acheng 主体绑定与连续性正文

- 局部编译按实际输出请求校验时间线和资产需求，保留前置镜头供完整连续性重放，不把上下文当作输出片段。按帧派生的浮点时长在校验副本中精确表示；真实时长不符仍拒绝通过。核对后插镜头、非整数秒片段及源稿不变。

- 使用新激活引擎编译时，复用人物身份、场景或道具内容的 Ref2VA 参考需要覆盖对应实体、来源图片和出场镜头的 Subject；纯首尾帧及构图锚点仍可直接使用 Picture。缺项保留草案并返回具体阻塞，不能交付通过。
- 连续性完整快照保留在检查报告中。正文使用镜头已写的起止状态与动作；额外画面约束使用 `continuity_cues` 声明登记事实、起点／终点、准确状态值和完整描述，状态不符拒绝通过。核对既有稿的 Subject 补齐、道具尾态、原对白及画面文字保留；历史编译包与在途任务仍对应原版本。结构通过不代替剧情、自然语言一致性或影像验收。

## 导演子代理与会话展示

- 子代理列表参考 Hermes 的紧凑状态条：无任务时完全隐藏（包括空列表的同步失败），默认折叠且标题单行；点击任务行查看结果或失败详情，进度更新和同会话重新读取保留折叠与选择。


- 导演可用 director_subagent 派发剧情、分镜、角色素材、连续性和审核建议，沿用父会话渠道并冻结本次任务上下文；等待复用 canvas_wait_tasks，结果按需完整读取或按 UTF-8 分块回收。同一 operationId 恢复原回执，不能换内容重用，也不重跑失败或已清理的任务。子任务沿用现有三个代理槽位，只返回建议，不直接改源稿、生成媒体或继续开子代理；由主导演核对后经原入口保存。对话区显示当前画布／导演的子任务、实时状态、失败原因及可展开结果，刷新恢复摘要，切换会话拒绝旧响应；停止主导演不自动取消已提交子任务，服务重启保留未完成任务的失败记录。核对 API 与 Codex CLI 渠道、中英文、深浅主题、窄屏及已有场次并行功能。

## MCP v3 工具精简

- 制作工具合并为 17 个统一入口，显式传 kind/id。34 个旧制作名称以及图片流程、单 Clip 更新、旧文本更新入口从发现与执行中移除。核对迁移后的完整流程、原操作与运行恢复、两会话对象隔离，以及旧调用 TOOL_REMOVED 且无副作用。网页 REST 与历史埋点保留。完整映射见仓库 docs/mcp-v3-migration.md。

## 并行推进的续接与反馈

- “并行推进到 H3”可沿原工作继续推进创作阶段待审核的场次，为尚未授权的工作补充媒体授权，并使用本次明确选择的渠道补齐旧工作的缺失渠道。已经授权但停在待审核的工作可显式重试；运行中的代理与手动暂停状态保留，已完成场次不自动重生成。按钮显示提交中及回执，后台拒绝保持可见，全部已有工作时提示处理审核或恢复。共同基础和场次审核仍必须通过，不把收到推进请求显示成视频已开始。

## 生成与交付片段阅读视图

- 进入具体片段时，先显示时长、视频结果、状态、画面风格及画面／对白说明；摄影与起止状态使用阅读文案，完整源稿、参考、原始参数与前后衔接设置默认折叠。就绪片段可按当前制作模式生成视频，运行中禁止重复提交。核对首段、中间段、单段、中英文、深浅主题及窄屏；打开或展开说明不保存、不生成，原稿编辑和衔接保存仍可使用。

## 一键启动复用有效构建

- `dev:local`／`dev:services` 启动前按文件内容核对插件、共享 Agent 源码、依赖配置和构建产物。没有变化时复用已有产物；首次运行、源码或依赖变化、产物缺失或被改写时重新构建受影响部分。验证第二次启动跳过构建，以及修改源码或删除产物后仍能自动重建；编译失败不启动服务。
- 后台启动成功日志记录进程总耗时，以及模块导入、配置与锁、数据库、工作流、Agent 和任务恢复的分阶段耗时。下一次正常启动时检查这些字段，以区分编译等待和后台实际初始化；启动总耗时不包含启动后台之前的 npm 构建步骤。

## 导演 H3 参数与前端一致

- 正式导演 Clip 按前端当前保存的参数生成。通过提交请求临时覆盖模型、采样、尺寸、LoRA 或二采设置时，预检和提交拒绝不一致的值并列出差异字段；先在 Clip 中保存修改，再提交。历史任务和在途任务保留原输入。
- 使用已发布稿生成时，单段提交和批次快照保留当前 Clip 的模型、分辨率、采样、LoRA、二采及确认设置，不因重建已发布正文与参考而回退到节点旧参数。验证 Clip 设置与节点设置不同时，新任务采用 Clip 设置；既有批次仍保留原快照。

## 导演待发送队列刷新恢复

- 同一标签页刷新后恢复待发送指令、图片附件、顺序和暂停状态；复制标签页不接管原页队列。发送或插入途中刷新会保留该条指令并暂停队列，检查对话结果后再重试、移除或继续。浏览器存储失败时提示保留输入；旧版刷新前未保存的指令无法恢复。

## Acheng 编译版本跟随本机

- 设置与历史页不再提供固定编译器版本展示；导演阶段任务和连续性修订请求读取当前激活合同，不传历史 runtimeId 选择版本。历史回执中的实际版本及原批次快照仍保留。

- 使用 `npm run acheng:update` 手动更新并激活本机引擎；已有制作下次读取合同、编译和校验使用当前激活版本，不再要求先升级制作对象。`production_get_contract` 的 `runtimeId` 参数保留兼容，但不再选择编译版本。
- 检查局部编译只更新目标产物，其他场次的提示词与实际版本回执保留；版本切换不重做媒体，也不改变已提交编译请求或生成任务的输入。后续 Agent 回合同步当前 Skill，并保护工作空间本地修改。

## ComfyUI 预设任务超时

- ComfyUI 预设生成（包括 H3 Clip）的默认等待时间由 30 分钟延长至 120 分钟，可配置执行超时上限也延长至 120 分钟。验证任务运行超过 30 分钟后仍继续等待并接收结果；超过时限时，报错显示实际时限并提示检查 ComfyUI。

## 导演 Clip 时长

- 导演新规划或调整的每段 Clip 为 4–12 秒（含边界），保存源稿和编译前核对声明秒数与帧窗一致。验证长段按安全边界拆分、短尾在同场次内合并或重分配，且不加速对白、压缩动作或填充空镜。旧确认稿超窗时应说明受影响片段及方案，不能自动改稿或重生成。此项为 Agent 规划指令，仍需实际导演对话验收。

## H3 Clip 编辑说明

- 点击正式 H3 Clip 的“编辑说明”，查看当前制作源稿中的分镜、对白、摄影、入出镜状态及完整镜头字段；同时展示前后片段的续接设置，并可查看完整片段源稿、参考规划与本集连续性账本。核对首段、中间段、末段、单段、无视频结果、中英文及深浅主题；打开窗口不保存或生成，源稿与画布人工提示词分别保留。

## MCP 重放与验收入口

- 场次排布恢复原回执时标记重放；重复同步 Clip 跳过相同输入、已有绑定与正确顺序，保持画布与制作稿版本不变。返回体回归入口覆盖临时大制作稿和丢失响应恢复；只读审计报告完成任务的总调用次数、MCP 字节数和耗时，并校验历史全文与模型分页。核对实际业务恢复与人工编辑兼容，既有网页和生成行为保留。

## 画布保存与异常草稿恢复

- 正式图片节点缺少旧参考摘要时，移动节点、编辑标题及 Clip 配置可正常保存。不同节点和不同字段的并发编辑自动合并，同字段竞争保留冲突保护。
- 因后端 `data` 参数为 `undefined` 异常被拒绝的操作保留在草稿中，后端加载修复后点击“重新提交已保留操作”恢复；刷新和远端更新不自动重试，不丢历史输出，不解除其他校验拒绝。

## 主页画布预览

- 点击画布预览正常打开弹窗，使用项目摘要或已加载画布显示节点与连线数量。核对网格与列表视图中的打开、关闭和再次打开，以及没有封面的画布。

## MCP 超大返回治理

- MCP 写操作默认返回短回执，制作稿与历史版本默认返回摘要；完整内容显式选视图，支持分页或 UTF-8 分块。H3 模型目录默认返回分类数量，entries 必须指定 categories 和 pageSize，可用 query、cursor 筛选续读。画布导出返回固定内容的鉴权下载引用。核对外部旧调用迁移、历史全文完整读取、操作重放不重复执行，以及画布更新后原下载引用的内容与哈希不变。Backend 网页接口不指定 view 时保留完整响应；诊断统计与输出上限保持原样。

## 导演与人工编辑协同

- Clip、角色、场景和关键帧图片默认按当前已保存内容生成，不要求手改后重新编译发布；有效参考可以直接使用。核对正文、参考顺序、分镜、模型、采样参数及明确不使用风格的保存和执行。
- 导演重新编译采用三方合并，保留人工内容并更新其他字段；对象详情可比较并采用指定导演字段，关联参考、分镜及时长一起采用。生成期间可以保存下一版，当前任务使用原输入，旧输入产物保留历史且不会覆盖新选择。
- 新批量冻结当前画布输入；独立目标继续执行，缺失素材依赖绑定本批次精确任务一次。开启素材审核时等待批准，否则直接续接。刷新、暂停和恢复保留原快照与任务，不扩张范围或重新收费；显式 published 使用发布稿，旧批次保持原语义。
- 数据库升级前生成完整备份，新增可空执行快照，不重写旧发布稿、媒体和草稿。批次列表只返回输入摘要，单批次 `?view=inputs` 可读取原快照。以上为工程已实现的待验收行为，不代表真实模型媒体或用户验收通过。

- 导演浮窗标题栏提供固定定位按钮，跟随中和暂停时均可使用。点击后收起对话，读取 Backend 最新制作进度并恢复跟随，回到当前画布节点／具体 Clip；没有已报告的制作目标时按钮禁用。编辑占用等已有保护仍生效。核对手动平移后返回、目标推进、跨画布、窄屏、中英文及深浅主题。

- MCP 诊断页读取完整报告，恢复已有埋点的每日趋势、分工具趋势、工具调用链与导出内容。核对日期筛选、工具选择及链路明细与本地已有事件一致。

## 正式 Clip 手动编辑

- 制作画布中的正式 Clip 允许直接编辑提示词、参考图、角色参考组、分镜与续接配置，使用原有保存和生成入口。手动编辑保留原编译基线及历史输出；重新应用编译稿遇到人工修改时保留修改并提示冲突，不静默覆盖。
- 打开面板、刷新或收到素材更新时不自动重写正式 Clip 的正文和参考。核对手动修改后保存、另一窗口同步、生成前同步，以及角色参考与分镜表单的实际保存；任务结果及编译身份仍由 Backend 维护。
- 被旧正式 Clip 限制拒绝的草稿不自动重提；页面提供“重新提交手动编辑”，确认后先持久化替代命令，再在最新版本上保存原修改。核对拒绝后刷新、原命令保留、明确恢复和真正的远端冲突。

## 单 Clip 返修与正式风格

- 正式 Segment 可保存 H3 风格模板；片段详情可“采用用户修改”，核验目标、Clip 与画布版本后保存。已声明的柔光或不使用模板在默认参数策略下仍生效；未声明风格的旧稿沿用原默认策略。同步不把模板正文搬进源稿，其他人工冲突保留。
- 单目标编译同时指定场次时不扩大为整场；共用剧本块引用的镜头、事件、保持要求及前态重放依赖保留为校验上下文，其他 Clip 不进入输出或应用范围。定向读取返回占用运行、精确任务状态和下一步；影响占用 Clip 的编辑在写入前拒绝，无关 Clip 仍可编辑。
- 编辑、准备与发布工具统一短回执，场次源稿和连续性条目可定向读取。局部返修按定向读取、修改、检查编译、预览发布、授权后单条生成推进；未知响应恢复原回执，状态未变不换键重复提交。核对真实项目的同块跨 Clip 覆盖、风格清除、版本冲突、运行／待审核占用和工具大小；本次工程验证不提交媒体任务。

## H3 提示词精简

- 新验证运行版本取消 Ref2VA 正文的自动最低词数和按秒扩写，短镜头通常采用 350–500 英文词的建议范围；字数短本身不阻塞交付。人物身份和永久场景在同一 Segment 内只定义一次，各镜保留自己的位置、动作、声音、对白与尾态，正文不再混入写作指令。
- 检查真实渠道的新短镜头、多镜对白和复杂动作的生成质量、参考职责与连续性。显式字数要求仍有效，正式素材、时间窗、逐字对白和哈希回读检查保留；新建制作使用新的活动版本，历史正文和回执保持原样，下次编译采用当前激活版本。

## 连续性可读展示

- 连续性默认显示剧情状态，按关注事项、时间线、初始状态、变化、镜头要求和剧本依据分类。对象显示已登记名称，状态优先使用已有中文展示值；变化与镜头状态按变化前后、开始结束进行对照。原始编号和完整 JSON 收进技术详情，手工编辑默认折叠。
- 核对真实源稿的中文标签与无展示值旧记录、场景登记名称、问题筛选与定位、导演交接、删除后保存及断引用检查、发布版只读、中英文与深浅主题、窄屏弹窗滚动。展示不翻译或改写已有源稿状态值，保存与导演交接保留原始标识和契约。

## 导演 Clip 定位缩放

- 导演定位和 Clip 挂载就绪后的定位都按完整 H3 节点计算缩放，避免播放器占满视口后裁掉提示词、时间线和参数区域；完整可见时保持当前视图。保留具体 Clip 选择与原时间线定位流程。核对大尺寸节点、重复定位、导演浮窗占宽、窄屏和真实 H3 的 Clip 滚动。

## H3 长提示词中文翻译

- Clip 的“查看中文翻译”把多行合并为每批最多 4,000 个原文字符，顺序请求当前文本模型并显示完成进度；单行过长时沿句读／空白拆分，引用标记和 Unicode 字符保持完整。全部完成后显示完整中文预览；标题、空行、缩进和 N/A 保留。切回原文再查看中文复用完整译文，翻译不修改原提示词。
- 分段译文按身份组装，兼容完整 JSON 外的 Markdown／文档包装。模型返回长度说明、空内容、缺失／重复分段或改动引用标签／分镜标记时显示失败，停止后续批次，不缓存部分译文或自动重试；切换 Clip、编辑原文或离开面板会取消旧翻译，迟到结果不显示。核对真实渠道的长稿与最后一镜、完成进度、失败后手动重试、运行中切换与编辑、深浅主题和窄屏。

## 资产预检与制作工具

- 完整源稿可通过 production_hash_source 计算哈希，无需活动画布。编译诊断提供适用的合法修复示例，未完成草稿仍可编辑保存。
- 范围图片编译可在视频连续性尚未编写时应用资产结果；实际就绪的 H3 产物仍核验对应连续性回执。
- 未绑定分集准备合法目标时自动创建固定画布，不提交媒体。非法目标、旧 revision 和冲突 operationId 不应创建画布；重复或中断准备应恢复同一回执与布局。
- 准备回执写入失败时，制作绑定与节点一同回滚；已接受请求的稳定 seed 画布保留，可沿原 operationId 恢复。
- 新验证运行包支持明确选择的无头人形四格和蛇形解剖四格；默认角色板仍采用当前等高布局，历史批准资产与已提交运行保留实际版本。核对选择理由、分格比例、参考上传顺序及真实出图。

## Codex CLI 文本渠道

- 在“渠道”新增或编辑渠道，将渠道类型设为“Codex CLI”，再从本机 Codex 拉取并选择文本模型。复用运行 Backend 的电脑上的 Codex 登录与配置，无需在此填写 Base URL 或 API Key；配置导入导出保留渠道类型，现有 API 与 ComfyUI 渠道继续使用原设置。
- Agent 可选择渠道中的 Codex 模型，并使用原生 Codex 会话、工具、权限确认及推理档位。API 与 Codex 跨运行方式切换时提示新建对话，旧历史保留。核对默认文本模型、新建／恢复 CLI 会话及不支持模型的报错；模型目录不代表实际账号推理权限。
- 画布文本任务与图片分析通过 Backend 创建任务，以隔离的只读 Codex 会话返回文本；场次工作者复用原工作池。取消后迟到结果不回写，重启后未确认的运行中 CLI 文本请求不自动重跑。此渠道只声明文本／图片分析能力，不将 Codex 模型登记为生图、视频或音频模型。
- 本地模拟 Codex 与页面验证覆盖模型路由、临时图片、取消、任务终态及中英文、深浅主题、窄屏；实际 CLI 登录、模型权限和回复效果仍需使用验收。

## 复用渠道模型的内置 Agent

- Backend 内置 Agent 的新对话复用已有渠道配置中的文本模型；默认使用已选文本模型，输入框可按“渠道 / 模型”切换，无需另填地址或 API Key。支持 OpenAI Responses、OpenAI Chat Completions 和 Gemini 协议；模型须支持工具调用。ComfyUI 模型和浏览器自定义脚本不进入 Agent 模型列表。
- 对话、工具回包与终态保存在 Backend；画布操作继续通过共享 MCP。核对同名模型的渠道归属、跨模型续聊、图片附件及工具图片、Skill 读取／启停／草稿、双窗口目标画布绑定和断线历史恢复。只读本地文件工具不提供 Codex 的命令执行、任意文件修改或内置生图能力。
- 场次创作与自动审核复用同一文本模型配置及原工作池；工作者仅能读文件和返回结构化数据，媒体提交仍经正式制作流程。停止、请求失败或进程中断后不自动重跑未确认的工具；恢复结构化结果只读取原已完成回合。旧 Codex 对话保留，在历史页选择“Codex 历史对话”后仍可通过原运行时恢复，需保留 Codex 安装。
- 已通过本地模拟模型与 MCP 的针对性验证；各真实渠道的工具调用、视觉判断和正式制作效果仍需验收。

## 场次并行导演制作

- 共同素材可在生成前一次开启自动审核：授权持久化并冻结审核设置，就绪素材分批自动续接；人工批准后继续等待下一批，全部通过后结束。源稿变化或中断的未完成回合暂停；不确定结论转人工且不自动重复模型请求。核对刷新／重启、素材分批到达、源稿变化和人工接管。此授权只涵盖审核，不提交新的图片或视频任务。

- 共享资产画布无需场次记录即可启动“自动审核共同素材”。当前就绪的一批素材可先批准并留存证据；完整共同基础需对齐全素材再审核，不因单批通过而放行。无法判断或缺少媒体分析能力时转人工。重启后复用已缓存回包或回读原线程，不自动重跑；服务重载同时检查生产代理池忙碌状态。
- 场次返修保留原媒体，只将源稿改变的资产、关键帧与声明依赖下游标为需要重新审核，未变化素材继续保留有效身份；重新生成仍须明确授权。

- 场次启动、暂停、恢复与审核复用正式工作台的待确认操作记录。响应丢失后保留原请求，通过“用原请求取回执”恢复；未取回前禁止重复提交，仍可查看素材。代理创作／编译阶段也沿用既有轮询恢复进度；相同版本和相同节点集合不会触发连续读取；本场输入和媒体不变时，其他场次增加全局修订号不阻止审核。核对断网后恢复、异步旧快照到达及缺少实时事件时的矩阵更新。

- 正式剧目规划弹窗提供“保存草稿”：未选择审核模式或分镜图策略也能保留未确认设置；“保存并确认剧目规划”仍要求明确选择。草稿不作为新制作的默认设置，确认后的设置只初始化新制作，已有制作和在途任务保持原版本。

- 场次审核将全部资产决定与工作回执一次提交，任一版本或媒体校验失败时整体回滚；换图即使未改源稿也会使旧审核失效，H3 提交前再次核对真实图片。审核卡可展开分批资产与整场审核记录。跳过分镜图只免除关键帧，仍要求角色、场景、道具等必需资产存在。

- 新剧目开局可显式启用场次并行制作，必须选择全自动、全人工或分别配置共同基础／场次开拍审核的混合模式。共同资产及共同基础批准后，最多三个场次代理与三个编译任务并行推进到 H3 技术收口。旧制作不自动迁移、重生成或切换运行包。
- 工作台显示每场创作、资产、审核、编译、视频及完成状态；审核卡展示绑定版本的源稿与图片。前置资产可分批审核，批准后继续依赖素材；缺少真实媒体、分析失败或创作判断不确定时转人工。核对一个场次等待审核、暂停或失败时其他场次继续，以及中英文、深浅主题。
- “并行制作源稿”只授权源稿和编译，“并行推进到 H3”同时授权本次已就绪的媒体目标。网络断开、重复提交、暂停恢复及重启保留工作、线程、编译包和任务身份；失败不自动重试付费生成。独立链并行，尾帧／Motion Context 依赖按序解锁。
- 核对只修改 A 场时 B/C 有效成果可复用，其他场次发布不打断冻结运行，相关引用变化拒绝尚未提交的受影响目标。自动审核和整条真实媒体生产仍需现场验收，模拟执行器通过不能代替画面验收。本期不包含剪辑、声音后期和成片终审。


## H3 时间轴编辑与草稿恢复

- 修改 Clip 时长、插入、删除及拖动排序后能保存，刷新和另一窗口保持相同顺序与起点；字段校验失败显示“编辑未保存”，不冒充远端冲突。旧 `patch.start` 草稿在可明确恢复顺序时提供“修复时间轴并保留操作”，确认后保留其他编辑并重新提交；无法还原的草稿继续保留且暂停原样重提。检查拒绝后刷新、恢复中存储失败、并发排序及真正的字段冲突。

- 制作流程新建 H3 节点沿用保存的默认节点尺寸，场次空间按尺寸预留；已有节点及已预留布局保持原有几何。保存较大的 H3 默认布局后，经 MCP 准备新场次 Clip，对比与画布菜单直接创建的节点尺寸。

## 主页剧目与画布

- 主页项目列表按剧目和普通画布展示，每个剧目只显示一张卡片并打开剧目页；主页和画布页不再单独列出分集、场次及共享资产画布；画布页文件夹、总数及批量操作仅包含普通画布，移动菜单不再包含剧目。检查无画布的剧目、搜索、筛选、网格/列表、中英文和深浅主题。

- 首页“最近更新”仍从所有画布中选择最新项，包含剧目内部画布；点击继续编辑打开原画布。剧目和画布列表在剧目归属读完前显示占位，刷新和返回页面复用归属查询，避免内部画布先出现再消失；延迟分集／场次接口时检查标题、封面区域及列表，失败时显示加载失败且可重试。

## 导演会话内的制作入口

- 制作状态和“回到当前制作”入口集成在导演会话内，收起会话后外侧不再显示这两个控件，会话仍保留。展开后可查看当前片段／状态、打开任务与交付，或手动恢复制作跟随。核对恢复中状态、深浅主题、窄屏及会话草稿保留。

## 移除本地代理

- 设置页不再显示本地代理标签。导入曾开启代理的旧配置后再导出，渠道凭据和模型设置应保留，旧代理字段不再导出，请求也不再使用旧代理地址。画布生成继续经 Backend，独立媒体页面保持既有渠道调用。核对中英文及深浅主题。

## 主页媒体加载

- 主页与导演项目卡片复用画布已有的浏览器缩略图缓存，卡片进入可见区域后才加载图片或视频。首次未缓存的大图仍需下载原图；缓存生成后，刷新或返回主页应直接显示缩略图。查看预览仍使用原图，清理浏览器缓存后可重新生成缩略图。
- 项目封面按各自查询完成时间显示，单个慢查询不阻塞其他封面；离开再返回页面复用现有查询缓存。核对网格/列表、滚动、媒体加载失败、预览、中英文及深浅主题。

## 画布右键翻译走所选模型

- 在设置的「翻译模型」中选择任意已配置的文本模型，再右键画布文本节点翻译为中文或英文。翻译由 Backend 调用该渠道完成，译文作为新文本节点添加，原文保留；不再需要第三方翻译凭据。留空时按默认文本模型翻译，两个方向分别使用对应语言的翻译指令。
- 核对未配置文本模型、渠道缺少 Base URL 或 API Key、模型返回空内容时的错误提示，以及长文本、含换行和引用标记（如 `{{name}}`、`<Subject 1>`）的译文结构；模型返回的 Markdown 代码块包裹应被剥离。

## 文字分镜阅读与编辑

- 制作窗口统一保留同一排工作区标签，概览、剧本、角色与素材、分镜、生成与交付和设置与历史在同一窗口切换；具体场次、镜头、资产和 Clip 也保留标签及一致窗口尺寸。分镜列表按场次排列，直接显示镜头编号、标题、时长、对应片段及中文画面摘要，小缩略图不再占据主要阅读区域。搜索镜头、场次或画面内容后保留原镜头编号，空结果明确提示。
- 点击镜头展开画面、对白与片段入口；单镜窗口支持上一镜、下一镜和返回全部镜头。详细生成描述与摄影参数、分镜图、片段编排及尾帧／潜空间连续性设置默认折叠，原保存入口仍保留。核对深浅主题、窄屏、草稿保留及搜索／展开／切换不写入源稿、不启动生成。

## 正式关键帧参考统一

- 正式图片的参考卡、连线、自动生产与手动重生成使用同一编号清单，显示具体批准媒体、用途和版本，不混入旧输出或角色节点的其他服装图。准备目标或应用编译后同步画布，检查多角色同框、末槽风格图和重复准备。
- 画布增删、排序参考在同一事务内回写正式参考卡与依赖，导演参考卡保留为编译基线；人工画布参考独立保存并直接用于生成，不要求登记或批准。实际输入仍核对本轮顺序与媒体字节，缺失或悬空参考准确阻止对应目标。
- 参考更新保留已有任务的冻结输入与历史批准稿，不自动重生成。自然语言中的漏登对象仍需导演逐镜核查；工程测试不代替新一轮实图验收。
- 存量节点的手动提示词与正式稿不一致时，保留该节点及批准历史，不阻断其他工作游标、设置或审核保存；差异目标在下一次生成前仍须合并并重新准备，不能静默覆盖旧提示词。

## 制作节点布局

- Backend 持久化完整制作布局计划；网页、Agent、MCP 和执行器按同一计划准备节点。检查资产用途区、场次剧本与镜头单元、视频区，以及顶层 `layoutReceipt` 中的计划哈希、创建/复用节点和冲突诊断。
- 每集按正式场次分区；同场次的剧本、镜头图片/提示词和 H3 Clips 节点在同一区域，同场 Segment 共用一个 H3 节点，不同场次节点分开。跨场 Segment 在新准备时给出明确阻塞；场次与环境 ID 不同时，按正式场次映射分组。
- 按不同顺序、分批、并发和重放准备相同目标，位置与单元身份保持稳定；缺少前置参考的目标仍预留位置。用户移动或调整的节点作为锚点，新目标增量避让；文案、审核、生成状态变化不推动节点。横竖图片加载和智能面板展开不能改写新节点锚点位置。检查旧手动绑定保留、失败回滚、重启恢复及别名画布归属。

## 导演对话排队与插入引导

- Agent 运行期间输入框不再禁用：回车或“加入队列”把当前提示词、附件、画布引用、Skill 与权限模式快照入队，按提交先后逐条发送；队列在对话区上方显示条数与状态，可移除单项。排队项只出现在队列卡片中，真正提交后才进入对话时间线。
- “插入并引导”把该条移到本会话队列最前；若正在同一会话运行，先请求中断当前回合，等该会话的权威状态变为空闲后再优先发送；中断被拒绝或未确认空闲时保留该条并提示，不重复提交。普通“停止”会暂停本会话队列，队列区出现“继续队列”。 已暂停且当前空闲时，点击插入会恢复本会话队列并立即优先发送；运行中插入只在中断成功且确认空闲后恢复，失败保留原暂停状态。
- 队列按会话隔离，切换或删除会话只影响自己的条目；入队后画布引用被删除或画布已切换时该条标记失败并可重试，不静默丢弃。队列保存在本标签页的浏览器存储，刷新后恢复待发送项与暂停状态；发送使用入队时的内容与附件数据，不依赖稍后会被释放的临时链接。
- 核对：运行中连排两条并在回车与“加入队列”两种方式下入队、逐条发送顺序；运行中插入并确认中断后新指令先发；重复收到空闲状态不重复发送；停止后暂停与恢复；中英文文案、深浅主题与窄屏。

## 后台人工确认提醒

- 导演浮窗顶部提供“确认提醒”开关，对话和创作欢迎页均可操作，点击后才请求浏览器通知权限。允许并开启后，即使收起导演，切到其他标签页或应用时，待授权、已登记的导演选择、逐项模式的素材审核以及 H3 二采/人脸精修确认可发送系统提醒；复用任务中心现有事件和查询，不增加轮询。
- 同一事项在状态刷新、重连及当前标签刷新后不重复提醒；新素材/一采快照或新的确认请求可再次提醒。回到页面或处理完成会关闭对应通知，组内仍有事项时点击指向剩余项；通知被替换或已解除后不执行旧点击。
- 点击只返回原画布、确认对话或具体 H3 Clip，保留未发送草稿，不自动回答、审核或提交任务。权限拒绝、不支持或发送失败时仍显示标签标题和角标。核对中英文、深浅主题与窄屏；系统弹窗和声音受浏览器/系统通知设置影响，关闭页面后不提供推送。

## 制作 Skill 图片并发调度

- 授权多张图片后，先为互不依赖且已就绪的资产图与关键帧启动独立运行，再统一跟踪结果。共享同一已批准参考的图片可同时推进；某图待审核或缺少前置参考，只阻塞它的下游。
- 单张试跑、仅提示词和明确逐项确认保持原范围。各运行保留原幂等回执与任务记录，已有运行不拆分，执行器使用既有容量排队。核对风格母图批准后角色与场景同时提交，以及失败或未知回执不导致其他目标重复生成。

## 编辑说明入口与面板精简

- 选中正式制作节点后，从审查工具栏打开“编辑说明”；顶部不再重复显示入口。共享引用继续从“查看源资产”编辑来源。
- 资产说明窗口默认显示放大的预览和一份说明输入框；桌面预览区宽 280px、高度最高 420px，窄屏改为上下布局，点击预览可查看原图；版本、依赖和图片关联按需展开，展开后不重复说明输入框。采用、退回沿审查工具栏操作。核对草稿恢复、深浅主题与窄屏布局。

## 制作工具自动预检与明确阻塞

- 编译或启动生成前自动检查条件。只有故事、资产计划字段不完整、风格绑定缺失、仅提示词模式或旧目标待审核时，返回待处理原因、字段位置和下一步，不创建编译包或新媒体任务。已识别的独立缺项一并展示；合法待出图的风格母图和缺参考的视频草案仍可按原合同编译。
- 原幂等请求在 revision 变化后仍恢复原回执；请求与旧键冲突时指向原运行。预检不修改制作与任务记录，正式提交会再次核验，提交竞态和基础设施故障仍显示真实失败。核对 HTTP MCP 和页面内 Agent 行为一致。

## 制作图片参数传递

- 资产图与关键帧生成采用绑定节点的工作流参数和图片尺寸；验证设置横向比例后，ComfyUI 实际提交和归档尺寸均为横图。任务创建后修改节点不改变已提交参数。

## 待审核制作目标的重做指引

- 已生成但待审核的目标再次启动时，提示查看原结果、审核或退回，并明确暂停不释放占用。暂停后重试仍不能创建新任务；按正式流程退回且原批次无在途任务后才能重新生成。

## 导演中断回合恢复

- 中断回合保留已完成工具记录并明确显示中断。后台变化立即推送完整权威状态，运行期间用既有 15 秒心跳及沿后台声明心跳周期的轻量 HTTP 查询纠正丢事件或停滞事件流，重连和切回页面也核对状态。进程身份、版本与精确回合身份阻止旧响应覆盖新任务；核对失败不推断已完成。终态仅补读历史，不重发提示词或重复写入；工具完成文案改为等待下一步响应，不推测模型活动。

## 导演对话关闭宣传输出

- 导演 Skill 使用项目内 Git 子模块，`origin` 指向 `helishou/acheng-director-skill`。可在子模块直接开发、提交和推送；父仓库只记录提交指针。`acheng:update -- --local` 构建已提交 HEAD，未提交修改保留并阻止更新；普通更新只允许快进，回退仅切换运行包。已有制作下次编译和校验使用当前激活版本，历史产物保留实际版本，宣传输出继续关闭。
- 新建导演创作会话及阶段交付直接展示创作内容或必要问题，不再附带品牌开场、能力宣传、作者署名推广、关注引导和固定版权免责声明；后续续写同样遵循该规则。

## 移除画布全局提示词

- 普通画布和制作画布顶部不再显示全局提示词按钮及编辑弹层；核对中英文和深浅主题。
- 生图、视频请求和 H3 提示词增强使用各自显式提示词与参考，不再注入旧全局提示词。旧画布文本与未确认草稿保留可恢复；旧全局提示词改写候选可复制或忽略，不能再采用到已移除的功能。

## 画布内制作与共享资产

- 主导航分开“制作”和“画布”：制作先到剧目列表／总览，普通画布直接使用原生节点，不自动展开制作 SOP。主页分别提供剧目制作和自由画布入口；旧独立制作链接保留兼容能力。
- 剧目总览可保存并确认全剧大纲、制作要求、通用图片模型及角色／服装、场景、道具、风格、分镜／关键帧各类别的图片模型，另有视频模型和画幅。确认后作为新制作的默认值，已开始制作的分集与在途输入保留；单对象模型优先于类别模型，类别模型优先于通用模型。
- 共享资产画布在剧目总览中显示独立卡片，分集通过自己的入口打开固定画布。画布可直接返回当前剧目；地址保存剧目选择，刷新与返回不会丢失。规划保存检测并发修改，拒绝时保留编辑弹窗中的草稿。数据库升级先备份并保留已有总纲与绑定。
- 导演资产卡保存“剧目共享／本集专用”归属；共享资产从剧目共享画布的正式制作记录生产并批准，分集在采用同剧目当前批准版本后继续。未采用的共享素材不能在分集生成，共享画布拒绝关键帧、视频 Clip 和本集专用资产。旧导演稿无归属时保持原分集路径。验证重复采用、媒体字节未变时既有下游结果不误标过期，以及不同输入变化时正确标记下游。
- 已审核的分集资产提供“接入已有审核素材”预览和确认；Backend 核对分集发布版本、节点绑定、归档字节摘要及共享画布 revision，复用原媒体登记共享批准版本，并记录来源分集、节点、任务与审核凭据。原分集节点和任务保留，整个过程不提交生成。验证双击／未知回执重放、竞争编辑拒绝、同资产较新共享版本拒绝接收旧媒体及原始数据未变。
- 进入分集制作默认打开固定画布；首次进入未绑定分集或剧目共享资产时幂等准备画布。绑定后不提供改绑，普通画布删除入口保留绑定对象。
- 进入制作默认保留完整画布，导演对话由右下角气泡打开浮窗；收起后保留连接、输入与消息。制作目录收进“找画面”，对象说明、剧本、任务和历史按需打开编辑弹窗，保留旧稿、草稿、未知命令回执和版本恢复。
- 左上角使用同一个“剧目／集数”菜单切换分集与共享资产画布，标出当前项。选中正式节点后显示修改、采用图片、重做及对应镜头的生成视频操作；其他工具收进“更多”。采用图片先查看原图，再沿正式版本审核；生成视频定位对应 H3 Clip，多片段镜头要求明确选择。
- 选中节点的制作操作菜单显示在图片上方，留出名称间距；接近画布边缘时保持按钮可见。核对缩放、深浅主题和窄屏下的定位及“更多”菜单操作。
- 剧本保存为画布文本节点，移除顶部“本场剧本”按钮及独立剧本弹窗，目录直接定位正文节点。原场次与分块身份保留；普通文本协作编辑在同一事务中更新制作稿，编译回执标记需重编译，已发布历史、其他场次和节点布局保留。存量项目补齐缺失文本节点，不提交媒体生成；重复准备不能创建副本。
- 存量动作／对白块即使各自带节拍，也按同场连续内容合并阅读和目录，分镜不随对白重复；整场条目和后续重返同一环境的场次保留独立身份。关闭剧本或取消选择后，再从目录点击同一节点应重新选中并显示操作菜单，鼠标经过其他节点不隐藏当前制作菜单。
- 节点“编辑说明”只打开当前角色、镜头或视频片段，其他说明与设置按需展开。菜单显示正式审核状态和当前对象运行状态，已采用图片不重复出现采用按钮，生成中禁用再次生成；“更多”可查看本对象历史与来源、查看原图并填写原因后退回。历史按节点和 Clip 查询，浏览不会替换当前版本。剧本文本使用普通节点编辑器，已有未保存草稿保留可恢复。
- 历史窗口支持明确“选用这一版”，先查看原图或视频，再经 Backend 核对原成功任务、正式对象与归档媒体。画布和制作映射原子更新，失败回滚，未知回执沿原命令恢复。图片选回后仍需审核，旧输入结果保持标记，原任务、提示词与连续性决定保留；缺少正式任务来源的存量日志不能冒充已验证结果。
- 正式 Clip 不允许用普通画布还原操作绕过制作核验，应从节点历史入口选用；普通独立画布的 H3 输出还原继续可用。
- “任务与交付”默认显示批次、原生节点任务、失败原因、定位和下载；校验、发布、完整提示词和配置收进“高级与历史”的展开项。核对单独下载片段、下载制作包、同一运行暂停／恢复，以及带未保存剧本切集再返回和复制标签页草稿隔离。本轮页面验证使用本地合成视频和临时任务，不代表真实模型质量验收。
- 现有项目的无生成验收可用 `node scripts/test-production-live.mjs <分集 ID> [...]`：独立浏览器检查入口、目录、节点操作、剧本文本节点、H3 定位和已有片段下载，并核对制作与画布记录未改变。拒绝生产写入与媒体提交；它不验证新生成质量，只有一集的剧目也不能用于验证真实跨集切换。
- 项目卡片使用单一“进入制作”入口，分集卡片未绑定时也可进入并准备固定画布。旧导演地址继续兼容；画布列表打开同一画布，恢复原视角。
- 选中正式资产、分镜或 H3 Clip 后，对话显示可定位的对象标签。开始输入后锁定本条请求的对象；查看其他 Clip 不改写草稿关联。跨画布草稿先定位原对象再发送，生成仍使用原有授权链路。
- 共享资产在剧目资产画布审核后登记批准版本；各集采用同剧目版本。新批准版本在 Backend 传播并重新编译校验；并发编辑显示待处理原因，用户核对后恢复。旧结果、历史和在途输入保留，更新引用不会自动重做媒体。
- 准备目标只建立节点／Clip，不提交生成；重复请求恢复原准备回执并保留用户布局。生成视频直接显示在 H3 Output，定位具体 Clip 而不自动播放。
- 手动移动视角、查看其他目标或切换画布暂停跟随；回到当前制作恢复且不强制打开对话。桌面定位避开对话浮窗；窄屏浮窗展开时暂存最新待定位目标。核对进度刷新不抢视角、较旧响应不跳回旧目标，以及深浅主题、窄屏和刷新草稿恢复。
- 接入已有素材使用资产画布的素材入口及对象图片关联，批准前不作为共享正式输入。媒体生成仍需原有明确授权；本功能的自动化验证使用临时数据，不提交真实模型请求。

## 资产退回与工作流提示词

- 资产或关键帧退回后，已收口且没有在途任务的旧批次结束，允许以新运行重新生成；原任务和媒体记录保留。在途任务仍保留占用。
- 提供图片提示词时，工作流必须配置提示词入口；未配置时应报错，不能执行模板残留内容。

## 制作主页与画布主页

- 制作主页只显示项目入口和剧目列表，创意输入与示例收进导演浮窗。进入主页显示“今天想创作什么？”的小气泡，右下角三角指向导演按钮，可打开或关闭提示；收起浮窗保留创意草稿，示例只填入输入框。明确点击开始后才沿已有连接、忙碌保护和审批流程发送创作请求，不因进入主页或打开浮窗自动提交。
- 制作项目卡片提供单一“进入制作”操作，画布库继续提供画布打开与管理；只为已显示项目读取封面，不为缩略图加载整张画布。剧目列表支持名称搜索，并使用紧凑的子页标题。
- 主页分别提供剧目制作与自由画布入口，并保留最近项目、收藏、生成结果和任务。普通画布卡片不提供独立制作 SOP 入口，剧目相关项目可以返回所属剧目。
- 核对中英文、深浅主题、窄屏、空搜索结果、项目跳转、预览和新建弹窗。页面浏览及示例填入不得创建媒体任务。

## 导演工作台阅读与编辑体验

- 制作导航改为概览、剧本、角色与素材、分镜、生成与交付、设置与历史；常规页面优先显示正文、图片和任务状态，原始数据、哈希与完整关联记录集中到设置与历史。
- 剧本支持按场次阅读和按需编辑，连续对白块保持同一场，回到同一地点的后续场次保持独立。切换场次、目标定位和保存失败时应保留原有草稿；人物、对白和场景名称保留用户原文。
- 素材支持分类、搜索和原图预览；描述与画布关联按需展开。分镜卡片展示顺序、秒数与真实媒体，区分正式关键帧和已登记构图参考；漏绑镜头显示缺项，不自动创建绑定。
- 生成页展示视频结果与任务状态，生成设置折叠，发布和生成仍是分别操作。核对中英文、深浅主题、窄窗口、展开编辑和素材预览；查看或切换视图不得提交媒体任务。
- 中文用户的新导演对话与工作台可读源稿默认使用简体中文，包括分场名和正文、角色名称与外观、资产说明及镜头摘要；模型编译字段继续遵守 Acheng 语言合同，对白逐字保留原文。既有英文确认稿不会自动翻译。

- 制作跟随的“回到当前制作／打开 Agent”浮动按钮固定在页面右下角，不被 Ant Design 按钮的相对定位样式覆盖。核对窄窗口、页面滚动、深浅主题及点击后打开 Agent 的行为。

## H3 默认参数与制作规格

- 制作页可保存视频交付画幅；新视频创作第一次对话须在故事拆解或提示词前询问画幅，未确认时不得默认猜测。已明确指定或正式设置已有确认值时不重复询问；“沿用画布配置”写为 `videoAspectRatio=null`、`videoAspectRatioConfirmed=true`。纯资产包跳过该问题；画幅与角色四视图/关键帧用途分开。单集同步新 H3 节点读取 Backend 默认参数，更新已有 Clip 保留用户设置与旧结果。
- H3 设置显示生效值及来源，支持沿用保存默认或明确覆盖。`h3_preview_run` 与现有预检返回生效参数、参考映射、预计一采/二采尺寸及 planHash；修改版本或默认值后，旧 expectedPlanHash 提交应被拒绝。
- 单集经画布直接提交也检查正式画幅、分镜轨稳定镜头 ID/顺序/时长、完整导演正文和逐字对白。缺模型或启用的 LoRA 不应静默换值、关闭或降规格。
- 工作流输入与冻结参数在提交前核对，归档视频经 ffprobe 实测。一采/二采分别校验；规格不符保留任务和媒体历史，旧活动成片不被替换，批次剩余任务停止。ffprobe 不可用不能标为通过。

## Backend 编译与绑定诊断

- 从关联分集的画布启动批次，确认只在正式分集存储一份；相同请求恢复回执，暂停/恢复/状态回写共享同一批次。批次缺失应在提交前拒绝，回滚错误不能掩盖原始错误；旧画布侧关联记录不得作为第二个恢复批次执行。

- 制作 MCP 读取默认 `view=summary`；`view=source` 返回一个完整源稿快照，`view=artifacts` 配合 `targetIds` 返回指定完整提示词。编辑、发布和恢复返回 revision/哈希短回执。验证大型制作不再因重复返回源稿、正文和发布历史而失败；网页 API 的完整记录默认行为保持。

- `production_compile` 接受 `kind`（`canvas` 或 `episode`）、`id`、`expectedRevision` 和可选完整候选 `director`；调用本机当前激活版本的 `compile_assets.py` / `compile_h3.py` 与校验脚本，冻结 `preparedId`、逐目标诊断、正文哈希和真实媒体引用。准备操作不保存、不发布、不生成媒体。
- `production_apply_compilation` 用相同对象和精确 `preparedId` 原子保存草稿。验证只增加一次 revision、重复调用恢复原回执；并发编辑、结果字节改变、对象不符或媒体失效应拒绝，且没有生成任务。冻结结果沿用原 revision 和 operationId，不能通过修改请求重定基线。
- `production_diagnose_bindings` 应分别呈现源版本/状态、草稿绑定、发布绑定、节点活动图片、实际归档哈希和依赖提示词。纠正后的草稿可能与旧发布版本不同，应指出差异，不删除历史或替代媒体审核。
- 验证 Windows CRLF H3 正文与 LF 的词数一致，原始正文和哈希保持不变；旧 `py` 路径失效及 Microsoft Store Python 应可正确发现和调用。显式配置 `ACHENG_PYTHON` 后不得静默换解释器。

## 制作契约查询与只读预检

- HTTP MCP `tools/list` 中制作编辑工具应展示完整操作结构；`production_get_contract` 支持单项 operationType；runtimeId 保留兼容但不选择执行版本，返回 schema、合法示例及源稿模板。合同始终返回本机当前激活版本，当前引擎不可用时明确报错。
- 使用 `production_preflight(kind:episode/canvas,id)`，提交 `action` 和原正式 `request`。验证对象 brief、缺失 entity、非法模块状态、不存在的 patch 目标及错误源稿字段返回明确错误路径；预检不增加 revision、不写回执、不创建任务或改变授权。
- 未完成计划稿可以保存；发布和生成按各自条件检查。预检后修改 revision，正式提交仍应拒绝旧基线；相同 ID 的正式请求仍保持幂等。
- 在构建共享包后，使用 `node scripts/acheng/preflight.mjs director.json edit` 做离线检查；发布/生成可选相应 action。离线媒体归属与当前模型配置显示未验证，不能表示生成就绪；导出目录保留 preflight.json 和编译诊断。
- 用运行版本管理器构建并激活新兼容脚本版本后，超出 2900 词的 Ref2VA 正文不再因长度被拒绝，最低细节要求仍生效，正文完整保留。旧稿沿用原 runtimeId 和回执；显式升级后才用新版本重算提示词产物与回执，不重写制作源，也不改变镜头、片段分组或生成媒体。


## 画布概览中的智能图片缩略图

- 缩小包含已完成智能图片节点的画布，确认直接保存在节点上的单图结果在概览中正常显示，普通图片和组图仍正常；放大后保持同一结果。

## MCP v2 写入回执与查询

- 通过 HTTP MCP `initialize` 和 `tools/list` 检查版本化 schema：`canvas_apply_ops`、内联 `h3_update_clips`、`assets_add` 和 `assets_upsert_batch` 必须传稳定 `operationId`；内联 H3 更新还必须传 `expectedRevision`。`preparedId` 继续使用冻结方案自己的 ID，并拒绝覆盖。
- 每类写入用相同 ID 和请求提交两次，再用同 ID 改动内容。确认画布只增加一次 revision、素材只写入一次、回执简短，改内容返回 `OPERATION_ID_REUSED`。在准备/提交阶段中断并重开隔离 Backend 后，通过 `mcp_get_command_receipt` 恢复，不重提生成任务。
- 无效素材批次须全部回滚。成功回执不得返回整图、data URL 或长提示词；需要一项素材全文时用 `assets_get`。
- 确认 `assets_list` 默认每页 20 条且只返回摘要，筛选和完整分页在 Backend 存储层完成、重复更新时间的排序稳定；验证中文关键词及 `%`、`_` 按普通字符匹配。节点选区和 `nodeIds` 只返回目标节点完整数据及相关连线。
- 对照完整项目与定向 H3 Clip 上下文的提示词、引用顺序、角色服装推导和缺失素材错误。摘要/运行参数读取跳过引用编译；显式加入 `include:prompt` 或 `include:references` 时只编译一次，并返回项目 revision。
- 分别在初始读取、SSE 等待和轮询期间取消 `canvas_wait_tasks`；调用应及时停止，任务仍在后台运行。覆盖普通/H3 任务、SSE 断开回退、终态事件、精确 taskId 和跨重连总截止时间。确认插件声明轮询不会对同一注册表并发应用。
- `mcp_observability_report` 默认只返回摘要，支持日期/工具过滤，只有 `view=full` 返回逐日与工具转换明细；报告包含进程实例、MCP 契约版本、已加载 H3 版本和工具 schema 摘要。
- 在 `backend` 目录运行 `node ../scripts/benchmark-mcp-v2.mjs`。脚本会在同机对每种场景自动运行三轮，并写出 `artifacts/mcp-v2-performance-*.json`，记录 200/500/1000 节点和 100/1000/10000 素材优化前后中位数。该基准测本地 SQLite 和投影，不代表模型或生成服务延迟。

旧 MCP 客户端需要在发送前生成一次操作 ID，并把完全相同的请求保留用于恢复；超时后先查回执，不换 ID 重提。最小请求示例：

```json
{
  "name": "canvas_apply_ops",
  "arguments": {
    "projectId": "project-id",
    "operationId": "client-generated-stable-id",
    "expectedRevision": 12,
    "ops": [{ "type": "update_node", "id": "node-id", "patch": { "title": "新标题" } }]
  }
}
```

## MCP 契约与 H3 原子准备（1.5.11）

- 核对实际工具目录保留字段说明、整数/范围约束、数组限制、未知字段策略及声明的跨字段条件；更新插件时，已有工具的 schema 和 handler 一并更新，不仅重新启用旧注册。
- `h3_prepare_clip` 将正文/配置、现有角色服装选择及参考绑定组成同一个最终候选；`dryRun: true` 只预检不写入，版本冲突或最终引用非法时整笔拒绝。运行归属、结果和任务历史受保护；此工具不生成视频。
- 引用错误返回 `REFERENCE_INVALID`、具体 issue code 和 `retryPolicy: after_input_change`。H3 诊断读取明确声明 `readOnlyHint: true`，写入或混合预览/写入工具仍按可写处理；不能原样重提被拒请求。
- `h3_get_clip` 的 `include: ["result"]` 核对精确项目/节点/Clip/任务/storageKey；可用 taskId 与 storageKey 选择历史结果，二者不能在不包含 result 的总览查询中被忽略。其他 Clip 的任务或媒体直接拒绝；共享父任务须有本段完成/复用事件，不能凭父任务平铺媒体数组或目录最新文件验收。缺少证据时返回不可核验或错误，不猜结果。
- 核对同一生成幂等键只恢复原任务，不再次排队；将原键用于另一目标或请求必须拒绝，历史回执不覆盖新稿或新任务。隔离任务存储可验证此契约，不需要提交真实生成。
- 源码/构建、独立真实 HTTP 检查和当前 Backend/Hermes 生效分别验收。授权安全处理服务后加载 Backend/共享包并刷新 MCP 目录；配套 Hermes 客户端 Python 修复也须由运行进程实际加载，仅刷新画布工具声明不能代替。不得为部署验收改生产稿、历史输出或在途任务。

## H3 修改稿文件与冻结短句柄（1.5.10）

- `h3_prepare_clip_updates` 读取 Backend 用户的 Hermes `cache/scratch` 内 JSON 文件（一个 `INFINITE_CANVAS_PREPARED_UPDATES_ROOT` 可覆盖源目录），传精确目标与原始文件字节 SHA-256。文件包含 `formatVersion: 1`、`projectId`、`nodeId`、`expectedRevision`、`items: [{segmentId,before,update:{segmentId,patch或edits}}]`；修改已有根字段必须提供实际 before，基线过期、次数/引用/版本错误均在冻结前整批拒绝。
- 文件必须为允许目录内的绝对 `.json` 路径且摘要一致，沿用现有本地文件导入大小上限。方案冻结在 Backend 管理的文件中，与源稿和画布分开，MCP 重连后仍可恢复；载入后改源文件不会改变旧句柄。画布操作不由脚本或私有 RPC 代提交。
- 审核返回的有界 `changePreviews`、字段清单、选择策略及摘要后，`h3_update_clips` 仅传 `preparedId`，不重新输出内联 updates。载入已经完成预检且不写画布，可选 dryRun 再核对版本；按字段选择更小且精确等价的 edits/patch。默认保护 `<d>...</d>` 对白、duration、timeline 时间边界和正文时间范围，仅用户明确授权后才能在文件 allowChanges 中列出 dialogue/timing。编译通过和字节等价不代表创意质量通过。
- 提交与恢复沿用冻结的 operationId、revision 和 operations，复用现有原子事务；重复句柄只取原回执，不再次写入。`replayed: true` 表示历史提交值，不代表当前项目状态；版本冲突不自动 rebase。完成核验或明确放弃后，`h3_discard_clip_updates` 仅删除精确冻结文件，保留原稿、画布、媒体及数据库事务回执。
- 独立真实 MCP HTTP 测试覆盖十段191条修改、载入/预览零写入、一次提交、原始 Yjs 同步、取历史回执不覆盖新稿、跨连接恢复、中途回滚和清理。真实十段清理稿的本地隔离回放也逐项一致，未写生产画布。实际常驻 Backend/Hermes 注册与用户请求到完成的耗时仍需在授权安全重载后分别验证；协议/本地回放时间不是模型端到端提速结果。

## H3 叙事增量与字段投影（1.5.9）

- `h3_update_clips` 的每段 `edits` 指定 `field`、精确且区分大小写的 `find`、`replace` 和正整数 `expectedMatches`；不是正则或自动改稿。`timeline[].action` 等声明的字符串列按所选列统计总命中数，时间码和未指定字段保持不变；`patch` 只能同时修改不同根字段，完整 patch 旧用法保留。
- `dryRun: true` 整批预检，返回 `applied: false`、拟写值/摘要、有界差异样例和当前 revision，不落盘。核对范围后，以同一 edits 和该 `expectedRevision` 提交。`editSummary.remainingLiteralFields` 提醒其他声明的叙事字段仍有原文字面命中；它不授权改台词，也不代表语义已验收。找不到原文、命中数不符、引用无效或版本冲突均整批拒绝。
- `h3_get_clip` 的 `fields` 只回读指定叙事字段，支持交接和 timeline，缺失值单列 `missingFields`。只核对小字段时不要再传 `include: ["prompt"]`，它会明确请求语义/编译两份完整正文。
- 独立 MCP HTTP 测试已验证十段一次事务、未指定字段/运行绑定/历史结果保护、原始 Yjs 文档同步、预览零落盘，以及 Backend 中途拒绝后的完整回滚。用户重启 Backend 后，实际 Hermes 原生工具已提供 edits/dryRun/fields，独立十段预览/提交/回读验收通过：预览保持 revision 2，提交仅升至 3 一次，实际字段与回执摘要全部一致；次数不符、无效引用和旧 revision 均整批拒绝，目标值和版本不变。额外对照段保持不变，测试画布已删除并确认不存在。不修改生产画布、不生成媒体；功能验收不等于端到端耗时复测。

## H3 潜空间放大二采确认

## H3 工作台参数适配

- 选择四个本地 H3 模型，分别调整清晰度、W/H、尺寸预设及秒数。清晰度切换应同步尺寸，尺寸调整应同步短边清晰度；面板应显示 H3 比例、像素量与原生网格对齐后的实际尺寸，生成任务输入及记录与该结果一致。
- H3 秒数预设为 6/10/12/15，输入范围为 1–15 秒整数；超过范围应拒绝提交。普通 API 视频模型仍保留原秒数选项。
- 自动尺寸在图生/首尾帧模式下使用首帧比例，在文生/多参模式下使用工作流比例；清晰度仍决定像素量。验证旧式 9:16 配置与 W/H 显示一致，刷新后的历史记录保留实际输入。

## H3 四种本地视频模型

- 本地 ComfyUI 视频模型目录应包含 MiniMax H3 文生视频、首尾帧、多参视频、图生视频。文生不接图片，图生只接一张首帧图，首尾帧按参考顺序接两张图，多参按顺序接人物或场景参考图。
- 在工作流参数中检查提示词、时长、画幅、百万像素、采样及随机种子；参数初始值继承登记时的 H3 默认设置。错误输入场景不得回退其它模式；首尾帧提供第三张图片时应拒绝提交，不静默丢图。多参少于全部槽位时空槽应保持合法空值。

## 视频创作台本地工作流任务

- 选择未填写 API Key 的 ComfyUI 视频模型，在文生、单图和多图场景生成：应按模型的场景路由提交本地工作流，不再提示配置 API Key；明确不支持的场景应显示工作流配置错误，不回退 API。
- 生成中刷新或重新打开视频创作台，应按已保存的 Backend 任务 ID 继续查询，成功后显示结果；工作流失败、取消及缺少媒体时显示对应错误。检查 API 视频渠道仍校验密钥。

## 画布 Delete 删除选中节点

- 选中一个或多个普通节点后按 Delete，应删除选中节点及关联连线；Ctrl/Cmd+Z 应恢复。仅选 H3 节点时 Delete 不应删除节点；混选 H3 和普通节点时只删除普通节点，并保留 H3 节点及其选择。选中连线时 Delete/Backspace 继续删除连线。
- 在提示词、输入框、富文本及标记为忽略画布快捷键的区域按 Delete，应只处理当前编辑内容，不删除节点。Backspace 不删除选中节点。

## 角色图片变更同步下游参考

- 将角色连接到普通生成节点后切换主图，参考卡及下一次生成输入应立即跟随；通过网页或 MCP 替换、删除角色图片也应如此，包括替换前后图片数量相同的情况。刷新及另一窗口应看到同一选择。
- 存量引用指向已移除图片时，应自动使用当前主图。仍有效的独立服装选择及明确关闭图片的配置应保留；旧输出的历史参考快照保持原样，不自动重新生成。

## H3 分镜提示词中的角色资料

- 给角色节点填写描述，再在 H3 分镜编辑中生成提示词：自动生成的实体定义不应包含该角色描述。分别检查图片/服装参考和仅启用声线的角色；角色名称、参考图编号、服装与声线信息仍应保留。
- 在分镜编辑的实体定义中手动填写描述，生成提示词后应保留该内容；已有实体定义不会被自动清空。

## 主页创作工作台

- 刷新主页或从已加载画布返回时，分别检查竖图、横图、视频及占位封面：首屏高度不应随媒体加载变化，项目列表不应上下跳动；同一项目版本不应因生成日志或剧目数据较晚返回而换图。项目更新时间变化后允许更新封面。

- 首页按更新时间展示真实画布，支持项目名搜索、画布/短剧画布/收藏筛选、网格/列表切换、新建并进入画布。收藏保存到 Backend，列表偏好保存在本机。检查刷新和多窗口收藏不同项目后仍保留结果。
- 项目封面优先使用已读取的近期生成结果，其次使用剧目封面或已加载节点中的图片；可见卡片没有封面时补读该项目最近一条成功记录，仍没有可用媒体时显示概览，不为首页加载全部画布详情。最近生成支持图片、视频和音频预览，来源画布存在时可打开。
- 最近任务展示后端状态、进度与失败原因，接收任务事件后更新。检查断连、部分接口失败、无项目/无结果、深浅主题、中英文和窄屏；本轮不调整生成链、重试或并发策略。

## H3 图片引用转角色

- 将 H3 Clip 已引用的普通图片或智能生图节点原位转为角色节点，参考区域应更新为角色名称与角色分类，并可打开角色服装设置；原引用图片、绑定与顺序应保留，不重复添加参考。
- 重新打开画布时，已有同源普通图片引用也应恢复为角色组。明确指定为分镜或场景的引用应保留原职责，不受源节点转换影响。

## H3 实时视频预览自动循环

- H3 生成中开启实时预览后，每批视频预览应默认静音、从头自动播放并循环，直到下一批预览到来；更新预览无需手动点播放，不应移动 Clip 时间轴、切换选中片段或续播已有成片。
- 生成完成或退出实时预览后，普通成片仍需手动起播：单段播完停在末帧，播放全部保持原有顺序续播；图片预览仍显示静态图片。

## H3 视觉风格模板单行布局

- 在“参数设置 → 模型与基础参数”查看视觉风格模板：标签与“不加模板”或已选模板应处于同一行，整行高度与相邻模型字段一致。长选项仍能打开、搜索、选择和清空；检查常用面板宽度与深浅主题。

## 角色节点缩略标识

- 在画布上缩小带封面图的角色节点：角色图标和名称应比普通媒体缩略标签明显，图片主体仍可看清；继续缩小到概览与紧凑模式时标识不应溢出节点。检查选中、悬停及深浅主题。

## 画布参考内容拖动排序

- 给智能生图节点连接两张以上参考图，在“参考内容”里拖动卡片交换顺序；刷新画布后顺序保持，下一次生成日志和实际提交输入按新顺序排列。角色卡片与普通图片卡片混排时也应如此。
- 拖动不应移动画布节点或断开连线；移除按钮、添加参考、悬停预览仍可使用。正在查看旧输出的历史参考快照保持只读，循环间接参考不应被当作直连参考改序。

## 工作流节点图中的模板追加节点

- 打开已导入的「2.1文生图」工作流，节点 #25 应显示“提示词模板追加”；悬停能看到完整类型 `PromptTemplateSuffix`，点击后仍能编辑已有的 `template` 字段。#4 → #25 → #10 的连接及导出后再导入的节点结构应保持一致。英文界面应显示对应英文名称。

## Qwen Image 2.1 双图编辑

- 通过画布统一模型用两张参考图运行 Qwen Image 2.1 编辑工作流：裁剪后应只保留这两张图片输入，提示词增强和输出节点仍在，并能正常返回本轮图片。单图、全部图片及缺少必需输入的场景仍按各自字段配置处理。

## H3 复制节点与模式切换

- 复制含角色服装、声线参考和历史输出的 H3 节点；切换原节点或副本的文生视频、多参考模式并刷新画布。原节点和副本的参考选择应各自保留，回到多参考模式后可见；编辑其中一个节点不应改动另一个节点的 Clip 数据。
- 原节点既有输出和生成日志应仍可查看。文生视频模式会隐藏不适用的参考槽，但切换模式不能删除已保存的参考。
- 分别用右键复制和 Ctrl+C/V 复制有输入、输出连线的节点：副本应保留可用的输入参考，不应连向未选中的下游节点；同时选中两个相连节点一起复制时，两者之间的连线应保留。

## H3 视觉风格模板设置

- 在「参数设置 → 模型与基础参数」选择视觉风格模板，确认当前 Clip 与全局配置范围各自生效；全局选择应同步已有 Clip 并由新 Clip 继承。清空选项后不再注入模板词。
- 保存 Ref2VA 分镜后，编辑区的 `detailed_description` 不应出现模板全文；运行日志和实际提交提示词应在该段开头包含所选模板词一次。I2V、FL2V、T2V 的模板词应进入 `integrated_multimodal_description`。旧提示词已有模板前缀时，运行提交应去重，改选或清空后按新设置生效；刷新画布不应改写保存的提示词。
- 导出、导入或设为默认参数时，模板选择应跟随设置，而提示词正文不应进入设置文件。

## H3 播放指针同步选中 Clip

- 在多 Clip 的 H3 时间轴刻度上点击其他 Clip，再拖动播放指针跨过 Clip 边界并拖回：选中高亮、当前 Clip 面板和预览应随指针切换。跳到时间轴末端时应选中最后一个 Clip。

## H3 节点设置范围

- 在一个有多个 Clip 的 H3 节点中切到「全局配置」，确认醒目提示出现；修改模型、采样参数和时长后，所有现有 Clip 都显示新值，时间轴起点随时长重排，提示词与参考素材仍各自保留。
- 在时间轴新增或插入 Clip，确认继承全局模式下改过的设置；切回「当前 Clip」再修改一项，确认仅当前 Clip 改变。刷新画布后，全局设置仍作用于新 Clip。切换中英文时检查范围按钮和提示文字。

## H3 节点界面语言

- 在中文界面打开 H3 节点，检查「提示词」「参数设置」「输出」、时间轴「视频/参考」、素材类型和分镜编辑字段标题显示中文。切换到 English 后应显示对应英文，再切回中文应立即恢复；`summary` 等提示词结构字段的实际内容与生成提交格式不应改变。

## H3 尾帧参考与潜空间续写

- 还原带运行时尾帧的历史输出参数时，ref 区域只恢复原始可编辑参考、作者提示词及保存模式；临时尾帧、实际运行模式和注入提示词仍保留在历史日志，不固化为配置。旧替换首帧日志只有原素材可核实时才还原；缺失时拒绝，不能静默丢参考。手工加入的同名图片保持原意。

- 「尾帧接续」改为「尾帧参考」。开启本段开关后，下一段运行时截取本段尾帧，追加到图片参考组末尾，确定下一段首帧的人物姿态、持物关系、动作进度及场景状态；不替换下一段原有首尾帧、分镜图或合成分镜图，不重编号原图片引用，允许按下一段机位重建构图，但原分镜不能覆盖继承的首状态或重复已完成的动作。
- 下一段以多参考模式接收追加尾帧，实际运行模式和参考槽写入生成日志；保留画布保存的模式、参考绑定与提示词。单独运行下一段同样适用。缺少上一段成品或追加后超过现有 9 张图片上限时明确拒绝；旧首帧替换方式的结果不作为新任务缓存复用。
- 「潜空间续写」独立传递视频/音频潜变量和上下文参数。只开启尾帧参考时不得自动开启潜空间续写；两项同时开启时各自发挥作用。
- 历史日志的尾帧仍按其原始输入显示，可从已有媒体记录打开预览；媒体缺失时保留名称。核对新日志中追加参考的编号、原分镜指令与画布保存值一致，并验证刷新后名称和独立开关状态。

## H3 Clip 误删后撤销恢复提示词

- 删除一个已有提示词的 Clip 后立即按 Ctrl+Z，确认 Clip 与提示词恢复，编辑器不再持续显示「找不到 Clip」。再编辑并保存该提示词，刷新画布后核对内容仍在。
- 同节点其他 Clip 的提示词应保持可编辑；若删除前有未确认的文本草稿，旧草稿应保留而非静默写入恢复后的新文本身份。
- Clip 恢复后立即打开分镜编辑并保存：等待新提示词会话完成读取后应能保存；旧身份草稿仍留在草稿箱，新文档不含旧草稿的未确认修改。若 Backend 尚未恢复该 Clip，编辑器应显示具体读取错误并保留表单修改。
- 同一画布保留一个因 Clip 文本身份变化而受阻的旧草稿，再在其他智能图片节点编辑提示词并点击生成：当前图片提示词应正常同步与提交，旧 Clip 草稿继续保留。当前图片提示词自身同步失败时仍须阻止生成。

## 智能生图二次生成的参考范围

- 智能生图节点首次生成后，在没有实时图片参考、也没有显式恢复历史参考时打开参数设置，应继续显示文生图工作流字段，不得把自身结果或 `@` 候选算成已用参考。接入一张、两张图片以及选中两套角色服装时，设置面板应分别按实际输入切换；提示词中的 `@` 选择与实际生成器保持一致。
- 显式恢复旧结果时仍按快照参考数展示；清除历史参考后回到实时输入。循环当前输入与普通图片节点自身编辑参考保持原有行为。

- 将一个文本节点连到智能生图节点，并让该生图节点再连到另一个同时接有图片参考的生成节点。首次生成后再次点击前一个节点的生成：它应继续按纯文本输入选择文生图工作流；后一个节点仍应保留自己的图片参考。

## 循环图片输出预览对比

- 将多张图片组成有序输入组，连接到图片循环节点，同时提供一张固定参考图。生成后分别打开各轮输出预览：对比滑块左侧应是该轮对应的输入组图片；切换到同槽的历史结果后仍应对应当前输入槽。原输入已删除的旧循环槽不应误用固定参考图显示对比。普通图片结果仍按生成快照选择对比图。

## H3 潜空间二采兼容性预检

- ComfyUI 缺少 `H3LatentUpscalerNodeMegapixels` 时，开启潜空间放大二采并提交 Clip：Backend 应在一采任务开始前明确提示缺失节点，不再跑完一采才失败。安装兼容节点后，确认所选放大模型出现在 `NanFengH3LowPeakLatentUpscalerV15` 列表中，提交可继续。另行实测一采速度；预检仅解决已确认的迟发报错。
- 同时开启 H3 潜空间续写与潜空间放大二采时，应在采样前拒绝这组不兼容设置。

## H3 潜空间续写从中段接续

- 一组潜空间续写完成后，修改 Clip3 并运行当前及后续 Clip：Backend 应读取当前绑定的 Clip2 成片对应的画面与音频潜变量，只从 Clip3 开始生成，保留旧任务潜变量文件和 Clip1–2 成片；核对新任务的续写段号与归档结果。
- 改变 Clip3 的模型或尺寸、替换 Clip2 活动成片，或移走对应潜变量文件：应在 ComfyUI 采样任务开始前明确失败。本机 ComfyUI 根目录未配置时应提示不支持该续跑方式。

## H3 增强提示词传入原文

- 在 Clip 中填写含对白的完整六段式 Ref2VA 提示词并点击「增强提示词」：文本生成请求应包含编辑框当前的完整原文及参考素材清单；只有结构化提示词时不应再以“没有自由文本”为由拒绝。采用候选前检查主体引用与对白。
- 旧结构化稿前另有用户自由文本时，请求应同时包含两者，并把自由文本标为更高优先级。协作文本尚未同步完成时按钮应禁用，不应点击后毫无反应。

## 角色声线上传自动压缩

- 重启 Backend 后，在画布角色编辑器或角色资产编辑器上传大于 0.5 MB 的声线：活动声线应变为 24 kHz 单声道、64 kbps MP3，界面显示压缩前后大小，原媒体仍保留。小于等于 0.5 MB 的声线和普通音频资产上传应保持原格式。菲比角色与有对白的 H3 Clip 应引用已试听确认的压缩 MP3。
- Backend 尚未重启时，角色声线上传应明确提示压缩功能未加载，不应悄悄把大文件设为活动声线。

## 智能文字结果编辑

- 重启 Backend 后，双击已生成成功的智能文字节点结果：修改应保存到当前结果，同时保留原输入提示词。普通智能图片节点不应把媒体内容开放为文字编辑。

## H3 分镜编辑按提示词镜头数打开

- 在一个 Clip 的提示词中写两段行首 `[Shot N]`，同时加入四张分镜图。点击「分镜编辑」应只显示两镜；没有在提示词中明确指定图片的镜头应保持未绑定，可分别手动选择分镜图。完成后重新打开，镜头数与手动绑定保持不变。
- 图数与镜头数相等时，空镜头仍可按参考顺序初始化；已在提示词中明确绑定的镜头保持原顺序。重复或失效的绑定应清空，不增加镜头。

## H3 V15 LoRA 强度范围

- ComfyUI 重载修改后的 V15 自定义节点后，检查 `/object_info/NanFengH3MultiReferenceGeneratorV15`：八个 LoRA 强度输入均应允许 -4 到 10。把某个 Clip 的 LoRA 强度设为 7，确认画布保留该值，并核对新任务的 V15 实际输入和生成日志均为 7；高于 10 或低于 -4 的值应在提交前夹紧。旧日志不能证明新节点声明已加载。

## 智能图片节点工具

## MCP 画布状态自动分页

- 449 节点画布默认调用 `canvas_get_state` 应一次返回全部节点 ID、类型、标题和可用的生成模式，不带布局、媒体路径、metadata 或连线数组；`view: "graph"` 返回布局尺寸和连线。
- 指定 `projectId` 与相同 `ifRevision` 时只返回 `unchanged: true` 和项目摘要；revision 变化时返回新目录。与图关系、指定节点或分页参数混用时应报错。
- 摘要超过当前 MCP 输出上限（默认 512 KiB）时，应返回一页及 `nextNodeOffset`；按该位置继续读取，合并前核对各页的项目 revision 相同，并按连线 ID 去重。
- 可传 `nodeLimit` 主动控制单次节点数量与 token 开销。若单个节点摘要即使不带连线仍超限，应明确返回 `OUTPUT_TOO_LARGE`，不能给出无法前进的分页位置。

## MCP 定向画布读取瘦身

- `canvas_get_state({ nodeIds: ["<节点 id>"] })` 只返回涉及该节点的连线，同时保留项目总 `connectionCount`；未分页的 `view: "graph"` 返回全部连线。
- `canvas_inspect` 的 `nodes` 保留完整节点摘要，`referenceCandidates` 和 `generationTargets` 只保留挑选目标所需字段；参考候选仍可读 `storageKey`，生成目标仍可读模型和状态。

## MCP 大节点读取与失效 Clip ID

- 在包含大 H3 节点的画布上，`h3_get_node` 应返回当前 Clip 的稳定 ID 和顺序，不携带整段 metadata；再用返回的 ID 调 `h3_get_clip` 读取单段。
- `canvas_get_state({ nodeIds: ["<大节点 id>"] })` 应返回摘要和 `metadataTruncated: true`，不报 `OUTPUT_TOO_LARGE`；小节点仍返回完整 metadata。
- 删除或拼错的 Clip ID 应报 `SEGMENT_NOT_FOUND` 并建议调用 `h3_get_node`；重读索引后再试。更新 Backend 与 canvas-agent 运行产物后需重连 MCP 客户端。

- 组节点引用：组节点应使用透明、轻量的边框与标题样式，并显示右侧输出连接点；把组连接到生成节点后，组内有内容的图片、视频、音频、文本及可引用扩展节点都应作为输入，普通提示词面板的 `@` 列表应显示组内资源，生成配置的 `@` 列表应允许一次选择整组；组与单节点重复引用时不得重复发送同一资源。
- 节点参考栏：普通节点提示词面板、放大编辑器和生成配置输入框上方应显示当前输入节点；图片和视频显示缩略图并可悬停预览，文本、音频及扩展节点显示对应类型；组连接应展开显示组内每个有效内容节点，删除任一展开项都应断开整组连线。点击加号进入画布选择后可连续添加有效参考，已连接、目标自身、已通过组引用的组内节点及不可引用节点不可重复选择，按 ESC 或顶部提示返回输入框；新增连接后 `@` 列表应立即更新。
- 多图透明背景：展开包含透明 PNG 或 WebP 的多图节点时，主图与所有备选图的透明区域都应直接显示画布背景；切换主图前后不得出现白色或主题面板底色。
- 画布选择与平移：左下工具栏应能切换「选择」与「移动」模式并用图标显示当前模式；选择模式拖动空白区域应显示疏朗清晰的虚线框，虚线长度、间距和粗细在任意缩放比例下保持一致；移动模式应能从空白区域或节点上拖动画布。按住 Control 或空格应临时反转当前工具且不改变工具栏模式，即选择变移动、移动变范围选择；点击画布页任意按钮后按空格应只临时切换工具，不得再次触发该按钮；输入框和可编辑文本内仍可正常输入空格。中键平移以及 Shift/Cmd 追加选择节点应继续可用。
- 文档站国际化：访问文档站首页及 `/docs` 应直接显示英文，不得出现重定向循环；切换简体中文后 URL 应带 `/zh-CN` 且首页、顶部导航、侧边栏、正文、搜索框和页面操作文案均显示中文；刷新、站内跳转和再次切回 English 后语言应保持正确，搜索结果与 Markdown/LLM 文档内容不得混入另一种语言。
- 国际化基础框架：从页面右上角切换简体中文或 English 后，首页、顶部及移动端导航、版本弹窗、配置主面板、渠道编辑、模型选择、页面标题、页面描述和 Ant Design 内置文案应立即切换，刷新页面后保持所选语言；偏好设置中不应再显示语言选项，WebDAV 同步错误、提示词来源及其他尚未接入翻译的业务模块暂时仍可能显示中文。
- 全局弹层主题：全站 Dropdown、Menu、Select、Cascader、TreeSelect 等弹层在浅色主题下应使用白色背景、轻灰悬停和选中态，在深色主题下应使用深色背景与低对比度浅色交互态，不应再出现默认黑灰色块、文字对比不足或单个页面配色不一致。
- 画布节点缩放稳定性：选中任意节点并反复拖动四角缩放时，节点工具条应在缩放期间隐藏、松开后恢复，页面不应再出现 `Maximum update depth exceeded`。
- Agent MCP 初始化状态：首次进入空白对话、点击「新对话」或恢复历史对话后，无需先发送消息，对话区应立即显示 Codex 会话准备，并列出 `codex_apps`、`infinite-canvas`、`node_repl` 等完整 MCP 服务状态；全部服务进入终态前可输入并保留草稿，但发送按钮、上传和回车提交应禁用；可选 MCP 失败时应提示警告但允许发送，`infinite-canvas` 缺失或失败时应阻止发送并显示明确原因；首轮及后续任务运行期间再次收到的 MCP 状态只进入诊断日志，模型开始处理及回复完成后对话区不应残留初始化卡片。
- Agent 模型设置：连接 Canvas Agent 后，输入框左下方应显示当前 Codex 模型与推理强度；模型列表应来自当前账号实际可用模型且不显示内部审查模型或重复项，切换模型后强度选项随模型能力更新且无空白选项，刷新页面后保留选择，发送任务时实际使用所选模型和强度；本地控制台与右侧「日志」应记录本轮使用的模型和推理强度。
- Agent 新对话响应：一轮对话完成后点击「新对话」，聊天内容应在服务端确认切换后清空并进入空白对话；后台应串行创建线程并预热 MCP，多个标签页应按同一会话版本同步，旧 HTTP 响应不得覆盖较新的 SSE 状态，初始化完成前不能发送到上一条会话或重复创建线程；重启 Agent 后应重新恢复并预热已有活动线程，无法恢复的失效空线程应自动替换为可用的新线程。
- Agent 读取画布卡片：读取当前画布完成后，卡片应按非零类型显示文本、图片、配置、视频、音频、分组、其他节点及连线数量，例如「3 个文本、5 张图片、2 个配置、4 条连线」；空画布应显示「当前画布为空」，执行失败时仍应显示错误信息，刷新恢复历史后统计保持一致。
- Agent 首次发送响应：在空白新对话中输入内容并按回车后，输入框应立即清空、用户消息应立即出现在对话中，再显示「正在思考」；线程创建或发送失败时，原输入和附件应恢复；任务运行期间输入的新草稿不应在请求成功后被清空。
- Agent 动态工具信息：执行内置生图、查看图片、命令、文件修改或其他动态工具时，卡片标题应显示具体工具名称；执行失败时正文应显示真实错误原因，刷新并恢复历史对话后仍应保持一致，不再统一显示「工具操作已完成」。
- Agent 画布生图：重启 Canvas Agent 后，其自动生成的工作区 `AGENTS.md` 应同步为最新版指令（用户自行编写的其他 `AGENTS.md` 不应被覆盖）；输入“生成一张图片”时应调用 `canvas_generate_image`，通过当前画布节点创建并运行生成流程；只有明确输入“使用 Codex 内置生图/ImageGen 技能生成”时才允许调用内置能力，Codex App Server 返回的 `imageGeneration` 结果应显示在对话中并作为保持原比例的图片节点添加到当前画布；Agent 不应在没有生成结果时提前声称“已生成”。
- Agent 顶部栏：在对话、历史和日志之间新增「技能」标签并显示已加载数量；连接状态应位于左侧 Agent 标题旁，并与右侧新对话使用相同规格的文字按钮，只有内容标签显示选中线；标签图标始终显示，中英文模式下都应按标签区域的实际可用宽度隐藏文字并保留小号数量，空间足够时显示图标和文字，拖动宽度时不应裁切、换行、横向滚动或错位。
- Agent 输入框窄屏布局：底部上传、Skill、确认模式、权限模式、模型和思考程度控件在窄面板下应只显示图标，宽面板下恢复文字；所有纯图标操作悬停时应使用统一样式显示名称或当前状态，任意宽度都不出现横向溢出。
- Agent 本地 Skill 管理：连接 Canvas Agent 后进入「技能」，应能读取当前 Codex 工作空间发现的项目、个人、系统和管理员 Skill，并支持搜索、按范围筛选、刷新及启停；未能加载的 Skill 应通过可点击、可滚动的详情查看原因；画布在站点工作空间 `.agents/skills` 下创建的 Skill 应可新建、编辑和删除，其他来源只读且不得被画布改写；编辑期间文件被其他窗口修改时应拒绝覆盖，清空显示名称、短说明和默认提示词后旧值应被删除，同时保留图标、品牌色等未由当前界面管理的元数据；多个标签页同时连接时，任一页面的 Skill 变更应自动同步，断开或切换 Agent 时旧请求不得重新写回列表或弹出编辑器。
- Agent Skill 草稿生成：创建 Skill 时应提供「空白创建」「从当前对话生成草稿」「从当前画布生成草稿」三种入口；空对话不得发起生成，取消时不得写入文件，确认后才写入站点工作空间 `.agents/skills`；Agent 运行中应禁用生成，多标签页下对话和画布来源必须分别严格绑定发起请求的 `threadId` 和 `clientId`，生成期间外部 MCP 仍应操作最近聚焦页面；草稿运行时创建、启停、删除和更新 Skill 应被统一拒绝，点击停止应真实中断临时草稿 turn；草稿不得泄露本地路径、密钥、媒体数据、真实节点 ID 或任务进度等临时状态，普通中文斜杠文本与 `/imagine` 等命令必须保持完整，生成草稿使用的临时 turn 不得出现在 Agent 对话、历史或日志中。
- Agent Skill 调用：在技能页点击「使用」或在输入框输入 `/` 搜索并选择 Skill 后，Skill 应作为原子 token 插入正文，而不是显示在输入框上方；发送任务时应通过 Codex 原生结构化 Skill 输入执行，发送成功后清除选择，失败时保留；新建对话、断开连接、Skill 被停用或删除时也应清除失效选择，发送前、任务完成后和刷新历史后的用户消息文字与 token 位置应保持一致。
- Agent 输入框快捷引用：输入 `/` 后应显示已启用 Skill 列表，输入 `@` 后应显示当前画布的图片、视频、音频和文本素材，长列表使用较高的内部滚动区域；选中项应按当前光标位置插入正文，例如「这是第一张图 `@图片1` 融合第二张图 `@图片2`」，不再集中显示在输入框上方，按 `Backspace` 或 `Delete` 时应整块删除；发送时应保持原句顺序，按节点 ID 精确引用发起页面的素材，并把引用图片的实际内容交给 Codex；输入框和聊天记录都应将引用渲染为与正文基线对齐的紧凑标签，悬浮或聚焦后可预览图片、视频、音频或文本内容，不重复显示内部图片附件，切换会话或刷新后引用样式应保持；可用方向键、`Enter` 或 `Tab` 选择，`Esc` 应关闭候选菜单，候选菜单打开时回车不得误发送消息。
- Agent Markdown 样式：右侧 Agent 回复中的代码块应为横向占满消息区域、无语言标题和无双层边框的紧凑代码条，单行内容不应保留纵向大面积空白，复制操作仅在悬停时弱化显示；行内代码、链接在浅色和深色主题下应清晰；点击外部链接后应显示中文紧凑确认弹窗，长路径能够正常换行且复制、继续打开和关闭操作可用；点击 `/Users/`、`/home/` 等本地绝对文件路径时应改为提示在系统文件管理器中定位，支持复制路径，且浏览器地址不应跳转为 localhost 文件路径。
- Agent 工具确认模式：右侧面板标题栏不应再显示「工具确认」开关；对话输入框左下方应显示确认模式选择，默认选中「自动确认」，画布写入工具应直接执行；切换为「手动确认」后，画布写入工具应在对话中展示等待确认卡片，并支持批准或拒绝。
- Canvas Agent Codex 升级：启动 Canvas Agent 后应输出 Canvas Agent、内置 Codex 和本机 Codex 版本，实际运行的内置 Codex 应为 0.160.0；内置与本机版本不一致、未安装本机 Codex，或 npm 存在更新版本时应显示对应升级提醒，npm 检查失败不应阻止服务启动；Agent 模型下拉框应展示新 app-server 返回的 GPT-6 系列，能正常创建或恢复会话、发送消息并调用画布工具；运行中停止任务应只中断当前 turn，随后无需重启 Agent 即可继续发送新任务。
- Canvas Agent Debug：普通启动应通过公共 logger 输出 Info、Warn 和 Error 日志；使用 `npx -y @basketikun/canvas-agent --debug` 启动后还应输出 Debug 日志并显示日志文件路径，终端统一采用“`YYYY-MM-DD HH:mm:ss` 级别 消息 详情”的纯文本单行格式，`~/.infinite-canvas/logs/` 下应按启动日期生成相同格式的 `canvas-agent-YYYY-MM-DD.log`，同一天多次启动应追加到同一文件；日志中不应出现连接 token 或图片 Data URL 原文。
- Canvas Agent 凭据脱敏：Codex 与 Claude CLI 的 stderr 包含 Bearer token、`sk-` 密钥、显式 API key/token/authorization 赋值、ANSI 样式或跨输出分片的凭据时，调试日志和网页诊断事件均不应出现明文；普通 stderr 文本应保持不变。
- Canvas Agent 配置权限：在 Linux 和 macOS 上保存配置后，`~/.infinite-canvas` 权限应为 `0700`，`canvas-agent.json` 权限应为 `0600`，已有的宽松权限也应被纠正；配置应能继续正常读写，Windows 启动不受影响。
- Canvas Agent URL 自动连接：链接应在 `#` 后传递 `agentUrl` 和 `agentToken`，进入或选择具体画布时继续保留，读取后立即从地址栏移除，并可连接有效的本机、局域网或远程 HTTP(S) Agent 地址且不主动展开设置面板；缺少参数或地址无效时应展开设置并显示错误。
- 图片 API 模型参数：`gpt-image-*` 的生成和编辑请求不应发送 `response_format`，`dall-e-*` 请求仍应发送 `response_format: "b64_json"`。
- Canvas Agent Codex 日志：Codex app-server 输出带颜色或样式控制符及 UTC 时间的 stderr 时，本地日志和网页诊断日志应只显示一份 `YYYY-MM-DD HH:mm:ss` 本地时间和干净文本，不应出现重复 ISO 时间或 `[2m`、`[31m` 等 ANSI 转义内容。
- Agent HTTP 诊断日志：网页发送一条普通消息后，本地 Debug 日志不应重复输出 `/health`、`/canvas/state`、`/canvas/activate` 成功请求、流式增量或完整会话响应，只保留 HTTP 请求与 Codex 生命周期摘要；右侧「日志」应以单行时间线展示发送、开始、回复、工具、完成用量和错误，不再输出 userMessage started/completed、流式摘要、重复 threadId 或大段原始 JSON。
- Agent 排查日志：右侧「日志」中的排查视图应显示连接摘要，并可按错误、警告和信息筛选；向下查看日志时仅列表内部滚动，标题、连接状态、筛选数量和操作按钮保持固定；连续相同事件应折叠计数，单条日志可展开查看完整详情；原始 JSON、复制全部、复制最近错误和清空功能应继续可用，浅色与深色主题下均应清晰。
- Agent 排查日志顺序与跟随：日志应按时间从旧到新排列，进入日志或切换筛选时定位到最新事件；停留底部时自动跟随新日志，展开最后一条后应继续停留在完整详情底部，向上浏览后暂停跟随并显示与对话区视觉高度一致的居中圆形向下箭头，新日志数量只在悬浮提示中显示；列表底部不应出现额外留白，点击按钮后回到底部并恢复跟随。
- Agent 对话统计：用户消息应右对齐并使用透明无气泡的简洁排版，用户和 Codex 两侧均不显示人物头像，消息下方均不显示时间或 Token 信息；输入框上方应居中展示最新一次模型调用的输入、缓存、输出 Token 用量，不显示会话累计值，数值更新时应从旧值平滑滚动到新值而非突然跳变，新建、切换或删除当前会话后应清空旧统计。
- Agent 回复实时显示：在右侧 Agent 发送消息后，用户消息下方应立即出现“正在思考...”，任务运行期间不应闪退；工具完成后应显示 Codex 正在继续处理及已等待时长，等待超过 30 秒时提示可继续等待或停止本轮；Codex 的回复应在当前对话中持续显示，实时事件缺失时也应在任务完成后自动同步完整内容，无需切换到历史或日志再返回对话。模型繁忙等任务失败时应立即结束等待状态，在对话中显示中文错误原因和重试建议，诊断日志不应再把失败轮次记为“处理完成”，刷新历史后错误仍应保留。新建尚未发送首条消息的空会话不应反复出现历史读取失败。
- Agent 对话实时与历史一致性：运行包含思考、命令及画布工具的较长任务，在执行中刷新发起页面或打开第二个页面时，已出现的用户消息、思考过程、工具卡和回复前缀均应保留并继续更新；同一思考或工具只显示一张卡片，任务结束及再次刷新后内容、顺序和状态应一致。切换页面焦点不能改变本轮画布工具目标，发起页面断开后不得把图片或写操作转交其他画布，使用相同页面身份重连后才能继续处理。
- Agent 流式交互性能：发送长回复时文字应连续平滑出现，输入框、滚动和画布操作不应随回复变长而明显卡顿；长历史会话中只有当前流式消息持续更新，屏幕外消息不应造成明显布局压力；任务完成后应通过 SSE 自动同步完整历史，不再持续请求 `/health` 轮询状态。
- Agent 过程时间线：新建 Agent 对话后 Codex 应生成可读思考摘要，并在运行时依次显示中文的思考摘要、执行计划、命令执行、网页搜索、文件修改和画布工具活动；思考摘要的图标、标题和箭头应稳定保持在同一行，默认收起且无边框，点击箭头后才展开 Codex 实际返回的具体摘要，其中 Markdown 强调、列表和代码应正确渲染而非显示原始符号，多行代码块和文本流程图应保留原始换行并允许横向滚动，完成事件不应再用「已完成分析」覆盖已经收到的摘要；同一轮连续命令应合并为显示数量的无边框折叠行，折叠时不显示命令预览，单条展开后直接显示详情，多条展开后可逐条查看工作目录、耗时、退出状态和运行输出；其他工具调用继续使用紧凑卡片排版，状态图标、标题和状态文字保持在同一行；结构化任务进度不应混在对话时间线中，而应独立放在对话区下方、Token 统计上方，支持展开和折叠，并逐项实时更新「待处理」「进行中」「已完成」状态；新任务生成时默认展开，任务结束后保留最新结果，同一计划更新不应生成重复内容；文件详情展示文件路径与新增/修改/删除动作，工具详情不应出现请求 ID、英文工具名或原始 JSON；一轮对话结束自动同步历史以及刷新页面后从历史中 resume 对话时，思考摘要、命令和工具过程记录仍应完整保留并保持相同展示。
- Agent 权限控制：输入框可选择「请求批准」「自动审查」「完全访问」；请求批准模式下，Codex 编辑工作区外文件、执行受限命令或访问网络时应在对话中显示审批卡片，支持拒绝、允许一次和本会话允许，并能依次处理多个并发请求；提交决定后卡片应保持禁用等待，只有 Codex 确认处理后才移除；等待审批时刷新页面，未处理的审批卡应自动恢复且不能让任务永久卡住；自动审查模式应仅将需要用户决定的风险操作送入审批；完全访问必须先显示风险确认，启用后可访问网络和本机文件且不再请求审批；选择应在刷新后保留。

- Agent 图片消息：发送一张或多张图片附件后，图片应紧跟用户文字并在消息右侧显示为约 40px 的紧凑缩略图，不再撑大消息区域，单击缩略图应打开大图预览，打开或关闭预览不应改变消息间距或产生额外空行；任务运行中、完成同步历史、切换页面及重新进入历史对话后都应显示浏览器本地保存的图片缩略图，不应消失或把 attachmentId、附件使用说明等内部上下文回显到用户消息中；删除历史会话后应同步清理对应缩略图。

- Agent 工作目录指令：`canvas-agent/agent-instructions.md` 应作为独立维护源；重启 Canvas Agent 后，当前工作目录应自动生成 `AGENTS.md`；新建对话发送消息时，Codex 日志中的用户消息只包含本轮请求和必要的附件上下文，不再重复整段 Infinite Canvas 前置提示词，画布及工作台工具仍可正常调用。
- 画布文本设置：文本节点和生成配置节点切换到文本模式后应显示推理强度设置，可选择自动、低、中、高、极高；选择自动时默认 OpenAI Responses 请求不应携带 `reasoning`，选择其他档位时应携带所选强度，刷新画布后节点设置应保留；文本模型自定义调用脚本应能读取 `reasoningEffort`，OpenAI 模板应按自动或指定档位正确组装请求。

### 画布循环节点

- 将 8 个输入节点放入左侧有序组，设置起始序号与每轮数量，确认轮数随可用槽位自动计算且面板不提供手填轮数；序号越界时不提交任务。没有可计数输入时默认一轮。
- 将 8 张图片和 2 张固定参考连到循环，右侧连接 2 个生成节点后运行；确认 Backend 将它们按顺序纳入单个右侧有序组并补足到 8 个槽。所有结果都使用循环节点的模型与提示词，每轮参考内容依次对应输入槽；已有节点 ID、旧媒体与生成历史保留。重跑仍写回对应槽。
- 将两张可用图片放入左侧有序组，循环节点旧设置为“图片关闭”、每轮数量为 1 时仍应显示并运行 2 轮；左侧第 1/2 张图分别以可见参考线连接右侧第 1/2 个结果槽。改起始序号或每轮数量后，参考线随本轮实际输入更新，不保留上一轮计划的错位连线；缩小画布查看组连线概览时仍能看到逐槽参考关系。
- 将旧连线整理成「循环 → 生成 A → 生成 B」后运行，确认 A、B 都被纳入同一个输出有序组，分别承接前两轮；旧 A→B 连线被移除，不将 A 的结果传给 B。多余既有输出节点不删除。
- 分别设置图片、视频、音频和文本输出模式，确认生成面板的模型、提示词和参数与循环节点本身一致；四种结果均写入指定输出槽，重跑保留旧媒体/文本历史。
- 输入组包含文本提示词时，确认轮数按组内节点槽位数计算，每轮文本与循环提示词正确组合；`《计数》`、`《总数》`、`《进度》`按本轮序号替换。每轮数量大于 1 时按有序组相邻槽分批，不回绕。
- 在一轮失败、并行轮次反向完成和点击停止时确认任务只回写自己的槽；失败或停止后不启动待运行轮次，已完成轮次结果保留。重复准备同一个 runId 返回原输出组和槽位，不重复创建节点。
- 图片任务日志分开展示「固定 refs」和「本轮组图」。当本轮需要 1 张组图 + 2 张固定图、选用的工作流却只有 2 个图片输入槽时，运行前提示槽位不足；Backend 也拒绝提交到模型，不能静默丢掉第三张。选择具有 3 个图片输入槽的工作流后逐轮运行。
- Flux2-Klein 工作流若使用旧 Inspire 单模型加载节点，执行时转换为当前 ComfyUI 内置 CLIP/UNET 加载节点，不覆盖用户工作流文件；ComfyUI 服务恢复后用三图输入验证真实推理与结果归档。
- 并行轮次反向完成时结果仍归各自输出节点；失败或停止会取消在途任务，不再启动其余轮次。非媒体生成链选择并行时须明确拒绝提交；视频结果不得被图片生成节点静默当作参考图。

### 制作编译与引用回执

- 同一画布的上下文刷新保留已加载制作快照和对象编辑状态；离开画布或更换制作归属时清理，避免“找画面”目录被刷新清空。

- 准备正式 H3 Clip、应用编译包与发布同步共享输入投影，返回逐目标引用就绪/阻塞回执；缺少批准参考、源稿过期、人工冲突或在途执行时保留原输入。
- 制作、节点与 H3 编辑入口校验字段及类型；metadata 按字段合并，正式 Clip 的编译字段需通过源稿修改后重新编译。
- MCP 编译携带 operationId 后在后台串行执行，立即返回持久回执；可查询编译、失败、中断与应用结果，响应未知时查询原 ID，避免重复编译。
- 制作记录支持产物索引、源稿分区、版本绑定分页和 UTF-8 分块；正常 Agent 流程仅消费短状态和诊断，不读取或审核编译正文。
- 已验证真实历史记录的分页/分块完整性、常驻 MCP 新合同及实际生产页面的目录、对象历史、H3 定位和交付下载；检查未改变正式记录、画布或媒体绑定，仍待用户确认验收。

### 制作连续性边界防漏

- 编译前必须逐相邻 Segment 明确尾帧参考、Motion Context 及具体承接/断链依据；草案可保存，缺项、重复/错位边界、空理由或整批统一模板理由全关时，编译、发布与新生成会返回诊断。
- 正式 Clip 两项开关从源稿投影，默认配置不能覆盖，普通 Clip 编辑与运行参数不能改写正式决定。末段关闭出边，连续组包含其收尾 Clip；不会因更新源稿自动重跑旧媒体。
- 后台编译允许精确匹配正式解析器核验的冻结参考路径，并统一资产计划与 Segment 的冻结文件身份；不放开任意包外路径，不把缺参考草案标为就绪。

### 连续性账本与导演工作台

- 打开「连续性」工作区，确认显示已登记来源覆盖、当前报告与运行包新鲜度、受影响镜头/片段及语义发现限制。检查对象状态轨迹和镜头衔接；时间线未知时不得画继承连线。
- 保存 v2 partial 账本并执行幂等检查，查看持久报告。变化、缺少基线的保持、覆盖缺项、非法事件帧和过期来源摘要必须保持阻塞。登记范围通过不得宣称未登记剧情事实或实际影像已获独立验证。
- 确认同一目标范围报告同时门禁 H3 就绪状态、ready 产物发布和原生 Clip 生成。缺失、过期或范围不符会阻塞对应 Segment；其他 Segment 的局部问题不应阻塞已覆盖且无问题的目标。发布草稿不得生成媒体。
- 在工作区修复问题、保存并重检，只有新报告确认后才显示已解决。编辑不写派生快照，也不提交媒体。刷新及浏览器历史应保留视图、对象、镜头和问题定位，并保留未保存编辑。
- 以仅诊断方式检查旧稿。查看建议的 v2 账本、目标运行包、源 revision、等价转换、仅留历史字段、语义缺项、未应用的推测建议、诊断和在途运行；只有绑定预览的明确升级可切换草稿，历史投影和媒体仍可查看。
- 检查中英文、深浅主题、窄屏详情、只读发布快照、未保存表单期间的事件更新，以及返回来源镜头、剧本或资产的导航。
