# Local Development

The Backend manages data, media, and canvas tasks; `web/` provides the interface. Agent and MCP are integrated into the Backend, while port 17371 is a compatibility service. See [Quick Start](/docs/overview/quick-start) for installation, backups, and LAN configuration.

## Start from the repository root

```bash
> **git-bash 用户注意**：Windows 上 `C:\Program Files
odejs\corepack` 与 `%APPDATA%
pm\pnpm`
> 是 POSIX sh shim，在 MSYS 环境下会把 `/c/...` 解析成 `<当前盘>:\c\...`，报
> `Cannot find module 'E:\c\Program Files
odejs
ode_modules\corepack\dist\corepack.js'`。
> 这时改用 `npm run <脚本名>`（根脚本已走 `scripts/pnpm.mjs` 启动器，不经过 shim），
> 或直接 `node scripts/pnpm.mjs --filter <包> run <脚本>`。cmd / PowerShell 下 `corepack pnpm` 不受影响。

corepack pnpm install --frozen-lockfile
corepack pnpm run dev
```

Open `http://localhost:3001`. Root startup commands build `canvas-agent/dist` before starting the Backend (17370) and Web (3001); a failed shared build prevents dependent services from starting. Build the shared package yourself before invoking workspace commands directly. Backend `dev` and `dev:watch` use guarded automatic reload: edits are coalesced, running or confirmation tasks, Agent/production turns and writes delay restart. `dev:once` starts once. Shared Agent source changes need a build; the watcher observes the resulting dist changes. HTTP/MCP connections reconnect after reload.

API channels require your endpoint, key, and model settings. Local ComfyUI needs its service and workflows without an OpenAI API key; canvas editing alone needs no model endpoint. Codex CLI is installed only when needed.

## Start the documentation site

```bash
cd docs
bun run dev
```

Common locations:

- Canvas, pages, and interactions: `web/`
- Prompt caching: `web/src/services/api/prompts.ts`
- Documentation content: `docs/content/docs/`
