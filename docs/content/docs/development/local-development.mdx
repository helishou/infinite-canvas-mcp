# Local Development

The Backend manages data, media, and canvas tasks; `web/` provides the interface. Agent and MCP are integrated into the Backend, while port 17371 is a compatibility service. See [Quick Start](/docs/overview/quick-start) for installation, backups, and LAN configuration.

## Start from the repository root

```bash
npm ci
npm run dev
```

Open `http://localhost:3001`. Root startup commands build `canvas-agent/dist` before starting the Backend (17370) and Web (3001); a failed shared build prevents dependent services from starting. Build the shared package yourself before invoking workspace commands directly. Backend `dev` does not restart on source edits; `dev:watch` does.

API channels require your endpoint, key, and model settings. Local ComfyUI needs its service and workflows without an OpenAI API key; canvas editing alone needs no model endpoint. Codex CLI is installed only when needed.

## Start the documentation site

```bash
cd docs
bun run dev
```

Common locations:

- Canvas, pages, and interactions: `web/`
- Prompt caching: `web/src/services/api/prompts.ts`
- Documentation content: `docs/content/docs/`
