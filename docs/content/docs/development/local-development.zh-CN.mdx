# 本地开发

Backend 管理数据、媒体与画布任务，`web/` 提供界面。Backend 已集成 Agent 和 MCP，独立 17371 服务只用于兼容旧客户端。安装、数据备份和局域网配置详见[快速开始](/zh-CN/docs/overview/quick-start)。

## 1. 从仓库根目录启动

```bash
> **git-bash 用户注意**：Windows 上 `C:\Program Files
odejs\corepack` 与 `%APPDATA%
pm\pnpm`
> 是 POSIX sh shim，在 MSYS 环境下会把 `/c/...` 解析成 `<当前盘>:\c\...`，报
> `Cannot find module 'E:\c\Program Files
odejs
ode_modules\corepack\dist\corepack.js'`。
> 这时改用 `npm run <脚本名>`（根脚本已走 `scripts/pnpm.mjs` 启动器，不经过 shim），
> 或直接 `node scripts/pnpm.mjs --filter <包> run <脚本>`。cmd / PowerShell 下 `corepack pnpm` 不受影响。

corepack pnpm install --frozen-lockfile
corepack pnpm run dev
```

前端默认访问：

```text
http://localhost:3001
```

根目录启动命令先构建 `canvas-agent/dist`，再启动 Backend（17370）与 Web（3001）；共享包构建失败时不会启动依赖它的服务。单独运行 workspace 命令前须先构建共享包。Backend 的 `dev` 与 `dev:watch` 默认使用安全自动重载：连续编辑合并，运行／待确认任务、Agent／生产代理回合和写请求未结束时延后重载。`dev:once` 单次启动。共享 Agent 源码需要先构建；重载器监听其 dist 更新。重载后 HTTP／MCP 连接重新建立。

## 2. 配置模型

API 渠道填写自己的地址、密钥和模型；本地 ComfyUI 配置服务与工作流，无需 OpenAI API Key。仅画布编辑不需要模型接口。Codex CLI 按需安装，不是基础运行依赖。

## 3. 启动文档站

如果需要单独调整文档站，在 `docs` 目录执行：

```bash
bun run dev
```

## 常见场景

- 改画布、页面和交互：主要看 `web/`
- 改提示词缓存：主要看 `web/src/services/api/prompts.ts`
- 改文档站内容：主要看 `docs/content/docs/`
