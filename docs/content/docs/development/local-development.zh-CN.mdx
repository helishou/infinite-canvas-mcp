# 本地开发

Backend 管理数据、媒体与画布任务，`web/` 提供界面。Backend 已集成 Agent 和 MCP，独立 17371 服务只用于兼容旧客户端。安装、数据备份和局域网配置详见[快速开始](/zh-CN/docs/overview/quick-start)。

## 1. 从仓库根目录启动

```bash
npm ci
npm run dev
```

前端默认访问：

```text
http://localhost:3001
```

根目录启动命令先构建 `canvas-agent/dist`，再启动 Backend（17370）与 Web（3001）；共享包构建失败时不会启动依赖它的服务。单独运行 workspace 命令前须先构建共享包。Backend 的 `dev` 不自动重启，`dev:watch` 才监听源码变化。

## 2. 配置模型

API 渠道填写自己的地址、密钥和模型；本地 ComfyUI 配置服务与工作流，无需 OpenAI API Key。仅画布编辑不需要模型接口。Codex CLI 按需安装，不是基础运行依赖。

## 3. 启动文档站

如果需要单独调整文档站，在 `docs` 目录执行：

```bash
bun run dev
```

## 常见场景

- 改画布、页面和交互：主要看 `web/`
- 改提示词缓存：主要看 `web/src/services/api/prompts.ts`
- 改文档站内容：主要看 `docs/content/docs/`
