# 快速开始

完整运行需要同时启动 Backend 和 `web/` 前端。

## Vercel 部署

根目录 `vercel.json` 只构建 `web/`。该方式适合预览前端；画布、素材和结构化配置的完整持久化仍需连接可访问的 Backend。

## 本地启动

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
npm install
npm run dev:local
```

启动后访问：

```text
http://localhost:3000
```

## Docker 启动

如果你需要基于当前源码构建镜像：

```bash
docker build -t infinite-canvas .
docker run --rm -p 3000:3000 infinite-canvas
```

## 首次使用建议

- 先打开右上角配置弹窗，填入自己的 `Base URL`、`API Key` 和模型名。
- 如果需要提示词仓库内容，打开 `/prompts` 会由浏览器前端直连拉取并使用内存缓存。
- 如果需要跨设备同步画布、素材和生成记录，可在配置弹窗中填写 WebDAV。

## 说明

- 画布项目、“我的素材”、生成记录和结构化配置统一写入本地 Backend SQLite；媒体文件写入 Backend 媒体目录，WebDAV 同步需要用户自行配置。
- AI API Key 随渠道配置保存在 Backend SQLite，由前端读取后直接请求对应的 OpenAI 兼容接口。
