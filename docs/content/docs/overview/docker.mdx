# Docker Deployment

## Use the published image

```bash
git clone git@github.com:helishou/infinite-canvas-mcp.git
cd infinite-canvas-mcp
docker compose up -d
```

Open `http://localhost:3000`.

## Build locally

```bash
docker compose -f docker-compose.local.yml up -d --build
```

## What the image includes

The main application image builds only the static frontend and serves it with nginx. AI requests are sent directly from the browser to your own OpenAI-compatible endpoints.

The Backend, Canvas Agent, MCP layer, and the H3 short-film production stack live at the source level and are **not** included in the Docker image. This deployment is suitable for a frontend preview; running the complete application requires starting the Backend locally and persisting its SQLite database and media directory. Use the three-process local mode from [Quick Start](/docs/overview/quick-start) for the full stack.

## Documentation image

The documentation in `docs/` is a separate Next.js standalone application with server capabilities.

```bash
cd docs
docker compose up -d
```

To build it from the current source:

```bash
cd docs
docker compose -f docker-compose.local.yml up -d --build
```

## Optional analytics

No analytics are enabled by default. A deployment can enable GA4, Baidu Analytics, or both at runtime:

| Variable | Description |
| --- | --- |
| `ANALYTICS_GA4_ID` | Google Analytics 4 measurement ID (`G-XXXX`) |
| `ANALYTICS_BAIDU_ID` | Baidu site ID, the hash after `hm.js?` |

```yaml
services:
  app:
    image: ghcr.io/basketikun/infinite-canvas:latest
    ports:
      - "3000:3000"
    environment:
      ANALYTICS_GA4_ID: G-XXXXXXXXXX
      ANALYTICS_BAIDU_ID: e8263761cc5c32f5f7a855b8203b965a
```

SPA route changes automatically report page views to enabled providers. Only configure analytics IDs on sites you control, and do not commit them to the repository.
