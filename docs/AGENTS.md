# 文档维护

继承[根约定](../AGENTS.md)。本文件同时规定其他目录代码改动触发的文档职责。

## 文件与语言

| 内容 | 位置 |
|---|---|
| 项目简介、核心功能、快速开始与文档入口 | 根 README.md，保持简洁 |
| AI 文档索引 | `docs/index.md`（英文）、`docs/index.zh-CN.md`（中文） |
| 已确认功能 | `docs/content/docs/overview/features.mdx` 及中文对应文件 |
| 后续计划 | `docs/content/docs/progress/todo.mdx` 及中文对应文件 |
| 本版本实际可测试变更 | `docs/content/docs/progress/pending-test.mdx` 及中文对应文件 |
| 版本级归纳 | 根 CHANGELOG.md 的 Unreleased |

文档站默认英文：无后缀 .mdx/meta.json 为英文，.zh-CN.mdx/meta.zh-CN.json 为中文。修改用户文档时同步对应语言和必要导航；AI 索引不移入内容目录。工程 AGENTS/Skill 可以保持中文，不为它们新增成套翻译。

## 状态流转

1. 用户可感知的功能、接口、工具变更完成后，在 pending-test 记录可测试行为；完成的 todo 移到这里。
2. CHANGELOG Unreleased 用一句中文作版本级归纳，前缀为 [新增]/[调整]/[修复]/[优化]，不复制逐条实现清单。
3. 用户确认测试通过后再纳入 features；代码已写、测试已跑不能代替用户确认。
4. 功能、待办或待测状态实际变化时才检查受影响文件；纯问答、审查、提交、内部指引修改无需例行翻动或报告“无需修改”。

## 准确性

- 说明用户可观察行为、使用条件和实际限制；不把实现细节堆进产品流程。
- SQLite/媒体目录是本地 Backend 权威，WebDAV 是可选同步副本，不写成账号云同步。
- AI Key 保存在渠道配置对应的 Backend 数据中，调用可能发生在浏览器或 Backend；安全说明保护真实边界，不做错误的单端承诺。
- Docker、模型和工作流能力按当前配置与验证证据说明，不能将旧待办写成现状或把构建通过写成生产验收。
- 不加会过期的“当前日期/近期计划”陈述；用户要求记录具体时间时才写日期。
- 链接指向现有页面/文件，名称与路由一致，示例参数必须符合当前接口；不传播失效机器路径、工具名或字段。

## 验证与发布

文档修改检查链接、语言、代码块与事实；只在改动影响文档站编译时做相关构建。版本整理和 tag 流程见[交付流程](../.agents/rules/delivery.md)。
